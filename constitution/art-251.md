# Art. 251
251. ބޭރުގެ އެއްވެސް ފަރާތަކަށް ރާއްޖޭގެ ސަރަޙައްދުގެ އެއްވެސް ބައެއް މިލްކުކޮށްނުދިނުމާއި، ޢަސްކަރީ ބޭނުންތަކަށް ދިނުން
(ހ) ދިވެހިރާއްޖޭގެ ސަރަޙައްދުގެ އެއްވެސް ބައެއް، ރާއްޖެއިން ބޭރުގެ އެއްވެސް ފަރާތަކަށް މިލްކުކޮށެއް ނުދެވޭނެއެވެ.
(ށ) ދިވެހިރާއްޖޭގެ އެއްވެސް ބައެއް ރާއްޖެއިން ބޭރުގެ އެއްވެސް ފަރާތަކަށް ކުއްޔަށް ނުވަތަ އެނޫން ގޮތަކަށްވެސް ދެވޭނީ އެންމެ ދިގުވެގެން ނުވަދިހަނުވަ އަހަރުގެ މުއްދަތަކަށެވެ.
(ނ) ރައްޔިތުންގެ މަޖިލީހުގެ ޖުމްލަ މެންބަރުންގެ އަޣުލަބިއްޔަތުން ފާސްވެގެން މެނުވީ ރާއްޖެއިން ބޭރުގެ ފަރާތަކަށް ދިވެހިރާއްޖޭގެ ސަރަޙައްދުގެ އެއްވެސް ބައެއް ޢަސްކަރީ ބޭނުމަކަށް ދީގެނެއްނުވާނެއެވެ.
