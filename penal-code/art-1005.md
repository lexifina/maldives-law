# Art. 1005
1005. އަދަބުތަކުގެ މިންވަރު ދައްކުވައިދޭ ތާވަލު
(ހ) މި މާއްދާގައިވާ "ތަފާތު އަދަބު އެއްހަމަ ކުރާ ތާވަލު" ގައިވާ ގޮތުގެމަތިން އެ ކުށަކަށް ކަނޑައެޅޭނެ އަދަބުގެ ޖުމްލަ މުއްދަތަށް ވުރެ އިތުރުނުވާ ގޮތުގެމަތިން ތަފާތު އެކިއެކި ބާވަތްތަކުން އަދަބު ކަނޑައެޅުމުގެ އިޚްތިޔާރު ކޯޓަށް ލިބިގެން ވެއެވެ.
