# Art. 82 (unnumbered item 1)
ކުށެއް ކުރަން ރޭވުމުގެ މަޤްޞަދު
(ށ) ކުށެއްކުރުމަށް ރޭވުމުގެ މަޤްޞަދު ކަމުގައި އަންނަނިވި ކަންކަން ހިމެނެއެވެ:
(1) ކުށްކުރަން ރޭވުމުގެ ސަބަބުން ހިތްވަރު ދިން ނުވަތަ މަގުފަހިކޮށްދިން ކުށް ކުރުން؛
(2) ކުށްކުރި ތަނުން ފިލުން؛
(3) ކުށްކޮށްގެން ލިބުނު ފައިދާ ބެހުން؛ އަދި
(4) ހަނުހުރުން ފިޔަވައި، އެހެން ކޮންމެވެސް ޢަމަލެއް ކޮށްގެން، އެ ކުށް ކުރިކަން ފޮރުވުން ނުވަތަ އެ ކަމާ ގުޅިގެން ޢަދުލު އިންޞާފު ޤާއިމުކުރުމަށް ހުރަސްއެޅުން.
