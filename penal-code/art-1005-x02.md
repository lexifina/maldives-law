# Art. 1005 (unnumbered item 2)
ގޭގައި ބަންދު ކުރުން
(ށ) ގޭގައި ބަންދުކުރުމަކީ ގެއެއްގައި ނުވަތަ ގެއެއްގެ މަޤާމު ދެވޭ ފަދަ ތަނެއްގައި ބަންދުކުރާ ބަންދުކުރުމެވެ. މިގޮތަށް ބަންދުކުރެވިފައިވާ މީހާ އޭނާ ބަންދުކުރެވިފައިވާ ތަނުން ގަވާއިދާ ޚިލާފަށް ނުކުމެގެން ނުވާނެއެވެ. އަދި ގަވާއިދާ ޚިލާފަށް ނުކުމެއްޖެނަމަ، އޭނާގެ މައްޗަށް އިތުރު އަދަބު ކަނޑައެޅިދާނެއެވެ.
