# Art. 220 (unnumbered item 1)
އިސްތިސްނާ
(ށ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ، އެކުރަނީ މި މާއްދާގެ (ހ) ގެ (2) ވަނަ ނަންބަރުގައި ބަޔާންކޮށްފައިވާ ކުށެއްކަމުގައެއް ނުބެލެވޭނެއެވެ:
(1) ދަޢުވާ ރައްދުވާ މީހާ ބެހުނީ އޭނާގެ އަމިއްލަ މުދަލާކަމުގައިވުން؛
(2) އެކަން އޭނާ ކުރަނީ އޭނާއަށް ޤާނޫނީ ގޮތުން ލިބިދޭ ޙައްޤުތަކުގެ ދާއިރާގެ ތެރޭގައި ކަމުގައިވުން؛ އަދި
(3) އަނެކާގެ މުދަލަށް ގެއްލުމެއް ލިބުނީ ދަޢުވާ ރައްދުވާ މީހާގެ މިލްކުވެރިކަމުގައިވާ ނުވަތަ ދަޢުވާ ރައްދުވާ މީހާ ކޮންޓްރޯލުކުރާ މުދަލެއްގެ ނުވަތަ ޚިދުމަތެއްގެ މައްޗަށް އެ މީހަކު ބުރަވުމުގެ ސަބަބުންކަމަށްވުމާއި، އެމީހަކު އެގޮތަށް ބުރަވީ، އެ މުދަލަކާ ގުޅޭގޮތުން ނުވަތަ ޚިދުމަތަކާ ގުޅޭގޮތުން ޤާނޫނީ ޙައްޤެއް ހޯދުމަކާ ނުލައިކަމުގައިވުން.
