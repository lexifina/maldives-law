# Art. 56
56. ހަމަހެއަށް އުނިކަން އައުން
(ހ) ކުށްކުރި މީހާ، ކުށްކުރި ހިނދުގައި ހުރީ އަންނަނިވި ޙާލަތްތަކުގެ ތެރެއިން ޙާލަތެއްގައިކަމުގައި ވާނަމަ، އޭނާ އެ ކުރި ކުށަށް މަޢާފުލިބިގެންވެއެވެ:
(1) ބައްޔެއްގެ ސަބަބުން މަޢާފުލިބެނިވި ދިފާޢެއް އެމީހަކަށް ލިބޭކަމަށް، މަޢާފު ލިބެނިވި ދިފާޢުތައް ބަޔާންކޮށްފައިވާ މިބާބުގެ އެހެން މާއްދާއެއްގެ ދަށުން ކަނޑައެޅިގެން ބަޔާންކޮށްފައި ނެތް ނުވަތަ ކަނޑައެޅިގެން ދޫކޮށްލައިފައިވެސް ނެތް ޙާލަތަކާ ގުޅޭ ގޮތުން، ޓެސްޓުތައް ހަދައިގެން ކަށަވަރުކުރެވެން އޮތް ބައްޔެއް ނުވަތަ އުނިކަމެއް އެމީހެއްގައި ހުރުންކަމަށްވުން؛ އަދި
(2) އެ އުނިކަން ނުވަތަ ބަލި އެހެން ހުރުމުގެ ސަބަބުން އަންނަނިވި ކަންކަން ކުރުމަށް އޭނާ ނުކުޅެދިގެންވުން؛
(i) ކުށުގެ ޢަމަލުގެ ގޮތުގައި ބެލެވޭ ޢަމަލުގެ ބާވަތާއި ނަތީޖާ އެކަށީގެންވާ ގޮތުގައި ވިސްނައިގަތުމަށް ނުކުޅެދިގެންވުން؛ ނުވަތަ
(ii) ކުށުގެ ޢަމަލުގެ ގޮތުގައި ބެލެވޭ ޢަމަލުގެ ނުރަނގަޅުކަން ވިސްނައިގަތުމަށް ނުކުޅެދިގެންވުން؛ ނުވަތަ
(iii) ކުށުގެ ޢަމަލުގެ ގޮތުގައި އޭނާ ހިންގި ޢަމަލު ހުއްޓުމަށްޓަކައި ބާރެއް ހިންގުމަށް ނުކުޅެދިގެންވުން.
