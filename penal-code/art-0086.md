# Art. 86
86. ދަރަޖަކުރުން
(ހ) މި ޤާނޫނުގެ 80 ވަނަ މާއްދާ "ކުށެއްކުރަން އުޅުން" އާއި މި ޤާނޫނުގެ 81 ވަނަ މާއްދާ "ކުށެއްކުރުމަށް އެދުން" އާއި މި ޤާނޫނުގެ 82 ވަނަ މާއްދާ "ކުށެއްކުރުމަށް ރޭވުން" ގައި ކަނޑައަޅާފައިވާ ކުށްކުށަކީ ކުރަން އުޅުނު ނުވަތަ ކުރަން އެދުނު ނުވަތަ ކުރުމަށް ރޭވި ކުށުގެ ދަރަޖައަށް ވުރެ އެއް ދަރަޖަ ތިރީގައިވާ ކުށް ކުށެވެ.
