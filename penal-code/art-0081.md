# Art. 81
81. ކުށް ކަނޑައެޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި އަންނަނިވި ޢަމަލު ކުރާ މީހާ އެހެން މީހަކު ލައްވާ ކުށެއް ކުރުވުމަށް އެދިއްޖެކަމުގައި ބެލެވޭނެއެވެ:
(1) މީހަކު އެ ޢަމަލު ކުރަނީ:
(i) ކުށެއްކުރުމަށް ބޭނުންވާ ކުށުގެ ނިޔަތް އޮވެގެން ކަމުގައިވުން؛
(ii) އެ ކުށް ކުރުމަށް ހިތްވަރު ދިނުމުގެގޮތުން ނުވަތަ ފަސޭހަކުރުމުގެ ގޮތުންކަމުގައިވުން.
(2) އަންނަނިވި ބާވަތުގެ ޢަމަލެއް ކުރީކަމުގައި ބެލެވޭނެ ކަމެއް ކުރުމަށް، އެހެން މީހަކަށް އަމުރުކުރުން، ހިތްވަރު ދިނުން، ނުވަތަ އެހެން މީހެއްގެ ގާތުން އެ ކަމަށް އެދުން:
(i) ކުށުގެ ޢަމަލުގެ ގޮތުގައި ބެލެވޭނެ ޢަމަލަކަށްވުން ނުވަތަ ކުށްކުރަން އުޅުމުގެ ޢަމަލެއްގެ ގޮތުގައި ބެލެވޭނެ ޢަމަލަކަށްވުން: ނުވަތަ
(ii) ކުށްކުރުމުގައި ނުވަތަ ކުށްކުރަން އުޅުމުގައި އެހީތެރިވެދީފިކަމަށް ނުވަތަ އެ ކަމުގައި ބައިވެރިވެއްޖެކަމަށް ބެލެވޭނެ ފަދަ ޢަމަލެއް ކަމުގައިވުން.
