# Art. 721 (unnumbered item 1)
މާނަކުރުން
(ށ)
(1) "މާލީ މުޢާމަލާތް" ކަމަށް ބުނެފައި އެވަނީ އަންނަނިވި ކަންކަން ހިމެނޭ ކޮންމެ މުޢާމަލާތަކަށެވެ:
(i) ވަޔަރ ނުވަތަ އެނޫންވެސް އެހެން ވަސީލަތެއް ބޭނުންކޮށްގެން އެއް ތަނުން އަނެއް ތަނަށް ފައިސާ ގެންދިއުން؛ ނުވަތަ
(ii) ފައިސާގެ ލިޔުމެއް އުފެއްދުން ނުވަތަ ބަދަލުކުރުން؛ ނުވަތަ
(iii) މުދަލަކަށްއޮތް މިލްކުވެރިކަމުގެ ޙައްޤު އެހެން ފަރާތަކަށް ބަދަލުކުރުން.
(2) "ފައިސާގެ ލިޔުން" ކަމަށް ބުނެފައި އެވަނީ:
(i) ދިވެހިރާއްޖޭގެ ފައިސާފޮއްޗަށާއި ފައިސާގެ ނޫޓަށާއި، އެހެން ޤައުމެއްގެވެސް އެފަދަ އެއްޗެއްސަށާއި، ޓްރެވެލަރސް ޗެކަށާއި، ބޭންކް ޗެކަށާއި އަދި މަނީ އޯޑަރަށެވެ؛ ނުވަތަ
(ii) އިންވެސްޓްމަންޓް ސެކިއުރިޓީއަށް ނުވަތަ ލިޔުން އަތުން އަތަށް ބަދަލުވާއިރު، އޭގެ މިލްކުވެރިކަންވެސް ބަދަލުވާގޮތަށް ފައިސާގެ ގޮތުގައި ބޭނުންކުރެވޭ އެހެނިހެން ލިޔެކިޔުމަށެވެ.
