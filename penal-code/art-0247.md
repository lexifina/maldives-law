# Art. 247
247. ކުށް ކަނޑައެޅުން
(ހ) އެނގިހުރެ، އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ.
(1) ކޮމްޕިއުޓަރ ޑޭޓާއެއް އިންޕުޓްކޮށްގެން ނުވަތަ އޮލްޓަރކޮށްގެން ނުވަތަ ޑިލީޓްކޮށްގެން ނުވަތަ ސަޕްރެސްކޮށްގެން، އެ ޑޭޓާ ސީދާ ގޮތެއްގައި ކިޔަން ނުވަތަ ދެނެގަންނަން ނޭނގުނަސް، އެ ޑޭޓާ ޞައްޙަނޫން އެއްޗަކަށް ވެގެންދިޔުމަށް މެދުވެރިކުރުވުން؛
(2) އަދި އެ ޢަމަލު ހިންގާފައިވަނީ، ޞައްޙަނޫން ޑޭޓާއަކީ ޤާނޫނީ އެންމެހައި ބޭނުންތަކަށް ޞައްޙަ ޑޭޓާއެއްގެ ގޮތުގައި ބަލައިގަނެވޭ އެއްޗަކަށް ނުވަތަ އެ މައްޗަށް ޢަމަލުކުރެވޭ އެއްޗަކަށް ހެދުމުގެ ނިޔަތުގައި ކަމަށްވުން.
