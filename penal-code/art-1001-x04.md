# Art. 1001 (unnumbered item 4)
އިންތިޤާލީ މަރުޙަލާގައި ޢަމަލުކުރާނެ ގޮތް
(ރ) މި ޤާނޫނަށް ޢަމަލުކުރަން ފެށުމުގެ ކުރިން ހިނގާފައިވާ ކުށްތަކަށް، މި ޤާނޫނުގެ ދަށުން އަދަބު ދޭއިރު، އެ ހާދިސާގައި ހިމެނޭ ގިނަ ކުށްތަކަށް ދަޢުވާ ކުރެވިފައިނުވާ ޙާލަތްތަކުގައި، މި މާއްދާގެ (ހ) ގައި ބަޔާންކޮށްފައިވާ "އަދަބު ކަނޑައެޅުމުގެ އަސާސީ މިންގަނޑު" ކަމަށް ބަލާނީ، މި ޤާނޫނުގެ 1002 ވަނަ މާއްދާގައި އޮތް ކަނޑައެޅޭ އަދަބުގެ މިންވަރު ބަޔާންކޮށްދޭ ތާވަލުގައި އޮތް އަދަބު ކަނޑައެޅުމުގެ އަސާސީ މިންގަނޑަށްވުރެ 3 (ތިނެއް) ދަރަޖަ މަތީ ދަރަޖައެވެ. އެއަށްފަހު، މި މާއްދާގެ (ށ) އާއި (ނ) ގައި ބަޔާންކޮށްފައިވާ ގޮތަށް ޢަމަލުކުރުމަށްފަހު، އަދަބުގެ މިންވަރު ކަނޑައަޅާނީއެވެ.
