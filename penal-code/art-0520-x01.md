# Art. 520 (unnumbered item 1)
އަނބުރާ ގެންދިއުމުގެ އިސްތިސްނާ
(ށ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލު ކުރާ މީހާ، އެކުރަނީ ކުށެއް ނޫނެވެ:
(1) ދޮގު ބަޔާނެއް ދިނުމަށްފަހު، އެ ބަޔާން ދިން މަޖިލީހުގައި، އެ ބަޔާން އަނބުރާ ގެންދިއުން؛
(2) ދޮގު ބަޔާނެއް ދީފައިވާކަން ސާބިތުވުމުގެކުރިން ނުވަތަ ދޮގުހަދާފައިވާކަން ސާބިތުވާނެކަން ކަށަވަރުވުމުގެ ކުރިން އެ ބަޔާން އަނބުރާ ގެންދިއުން؛ އަދި
(3) އެ ދޮގު ބަޔާނުގެ ސަބަބުން، އެ ބަޔާން ދިން މަޖިލީހުގައި ހިނގަމުން ދިޔަ ކަންކަމުގެ އަސްލަށް އަސަރުކުރުމުގެ ކުރިން އެ ބަޔާން އަނބުރާ ގެންދިއުން.
