# Art. 522
522. އެހެން މީހަކު ކުށެއް ކޮށްފިކަމުގެ ދޮގު މަޢުލޫމާތު ދިނުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ، އެކުރަނީ ކުށެކެވެ:
(1) ދޮގު މަޢުލޫމާތުކަން އެނގޭ މަޢުލޫމާތެއް ޤާނޫނު ތަންފީޒުކުރާ މުވައްޒަފަކަށް ދިނުން؛ އަދި
(2) އެ މަޢުލޫމާތު އެދެނީ، ޖިނާއީ ޢަމަލެއް މީހަކަށް ނިސްބަތްކުރުމުގެ މަޤްޞަދުގައި ކަމަށްވުން.
