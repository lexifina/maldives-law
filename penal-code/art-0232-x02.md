# Art. 232 (unnumbered item 2)
މާނަކުރުން
(ނ)
(1) "މަތީ ދަރަޖައަކަށް ރައްކާތެރިކުރެވިފައިވާ މަޢުލޫމާތު" ކަމަށް ބުނެފައި އެވަނީ، ހުއްދަ ލިބިގެންވާ މީހުންނަށް މެނުވީ ނުލިބޭ ގޮތަށް ރައްކާތެރިކުރެވިފައިވާ މަޢުލޫމާތަށެވެ.
(2) "މީހެއްގެ އަމިއްލަ މަޢުލޫމާތު" ކަމަށް ބުނެފައި އެވަނީ، ޢާންމުކޮށް ހާމަކުރުމަށް ޢާންމު މީހަކު ބޭނުންނުވާނެ މަޢުލޫމާތަށެވެ.
