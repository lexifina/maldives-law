# Art. 53 (unnumbered item 2)
އިސްތިސްނާ
(ނ) ކުށްކުރި ހިނދުގައި 18 އަހަރު ފުރިހަމަނުވާ ކުދިންގެ ތެރެއިން، މި މާއްދާގެ (ހ) އާއި (ށ) ގެ ދަށުން މަޢާފު ލިބެނިވި ދިފާޢުގެ ފައިދާ ލިބިގެންވާ ކުދިން، އިސްލާމީ ޝަރީޢަތުގައި ހައްދު ކަނޑައެޅިފައިވާ ކުށްތަކަށް ކުށުގެ ޒިންމާ ނަގަންވާނެއެވެ. އަދި މިފަދަ ކުށްތަކަށް އެކުއްޖެއްގެ މައްޗަށް މި ޤާނޫނުގައިވާ ގޮތަށް އަދަބު ކަނޑައަޅަންވާނީ އެކުއްޖެއްގެ ޢުމުރުން 18 އަހަރު ފުރިހަމަވުމަށްފަހުގައެވެ.
