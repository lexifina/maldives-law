# Art. 533 (unnumbered item 1)
މާނަކުރުން
(ށ) "ދައުލަތުގެ މުވައްޒަފު" ކަމަށް ބުނެފައި އެވަނީ، ދައުލަތް ހިންގުމުގެ ބާރާއި، ޤާނޫނު ހެދުމުގެ ބާރާއި، ޢަދުލު އިންޞާފު ޤާއިމުކުރުމުގެ ބާރު ލިބިގެންވާ ފަރާތްތަކުގެ މެންބަރުންނާއި، މިނިވަން މުވައްސަސާތަކުގެ މެންބަރުންނާއި މުވައްޒަފުން ހިމެނޭ ގޮތަށެވެ. މީގެތެރޭގައި ފަނޑިޔާރުންނާއި ރައްޔިތުންގެ މަޖިލީހުގެ މެންބަރުންނާއި ދައުލަތުގެ މަޤާމުތަކުން އިންތިޚާބުކުރެވޭ މަޤާމުތަކަށް ކުރިމަތިލައިގެން ތިބި މީހުންވެސް ހިމެނެއެވެ.
