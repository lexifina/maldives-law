# Art. 721
721. ކުށް ކަނޑައެޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) ޣައިރު ޤާނޫނީ ޙަރަކާތަކުން ހޯދައިފައިވާ ފައިސާކަން އެނގޭ ފައިސާއާ ގުޅޭގޮތުން އެއްވެސް މާލީ މުޢާމަލާތެއް ހިންގުން؛ އަދި
(2) އެ މާލީ މުޢާމަލާތް ހިންގުމުގެ މުޅި ބޭނުމަކީ ނުވަތަ އެ މުޢާމަލާތުން ޙާޞިލުކުރާ ބޭނުމަކީ:
(i) ޣައިރު ޤާނޫނީ ޢަމަލުތަކެއް ކުރުމަށް މަގުފަހިކުރުން ކަމުގައިވުން؛ ނުވަތަ
(ii) ޣައިރު ޤާނޫނީ ޢަމަލުން ލިބޭ ފައިސާގެ ބާވަތާއި، އެ ހުރި ތަނަކާއި، އެ ލިބުނު ތަނަކާއި، އަދި އޭގެ ވެރިފަރާތާއި އޭގެ މައްޗަށް ބާރު ހިންގާ ފަރާތް ފޮރުވުން؛ ނުވަތަ
(iii) ޤާނޫނު ބުނާގޮތުން އެފަދަ ފައިސާއާބެހޭ ގޮތުން ހުށަހަޅަންޖެހޭ މަޢުލޫމާތު ހުށަހެޅުމުން ސަލާމަތްވެގަތުން.
