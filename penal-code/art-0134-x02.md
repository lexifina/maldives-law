# Art. 134 (unnumbered item 2)
ޞިއްޙީ ފަރުވާއަށްޓަކައި އިސްތިސްނާކުރެވޭ ޙާލަތްތައް
(ނ) އަންނަނިވި ކަންކަމަށްޓަކައި ނުވަތަ އަންނަނިވި ގޮތުގެމަތިން، ޞިއްޙީގޮތުން ކުރަންޖެހޭ ކަމެއްކަމަށް ބެލެވޭކަމެއް ކުރުމަށްޓަކައި، ނުވަތަ ޞިއްޙީގޮތުން ބަލަންޖެހޭ ބެލުމަށްޓަކައި، ޑޮކްޓަރަކު ނުވަތަ ހުއްދަކުރެވިފައިވާ ޞިއްޙީ މަސައްކަތްތެރިއަކު ނުވަތަ ބެލެނިވެރިއަކު ނުވަތަ ދޮންމަންމައަކު ނުވަތަ ދޮންބައްޕައަކު ނުވަތަ ޤާނޫނީގޮތުން ބަލަދުވެރިއަކު، އަންނަނިވި ކަންކަން ކުރުމަކީ، މި ބާބުގައި ބަޔާންކޮށްފައިވާ ކުށެއް ކުރީކަމުގައެއް ނުބެލެވޭނެއެވެ:
(1) ޞިއްޙީ ފަރުވާއެއް ދިނުމަށްޓަކައި ހިންގާ ޢަމަލަކަށްވުން؛
(2) އެ ޢަމަލު ހިންގަނީ ޤަބޫލުކުރެވޭ ޞިއްޙީ މިންގަނޑުތަކާ އެއްގޮތަށްކަމުގައިވުން؛ އަދި
(3) އެކަން ކުރުމަށްޓަކައި ޞިއްޙީ ރޮނގުން ބޭނުންވާ ތަމްރީނާއި ތަޖުރިބާ އެކަން ކުރާމީހާގެ ކިބައިގައި ހުރުން.
