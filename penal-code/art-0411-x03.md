# Art. 411 (unnumbered item 3)
ހަތަރު ހެކިންގެ އުސޫލު
(ނ) މި މާއްދާގެ (ހ) ގެ 1 ވަނަ ނަންބަރުގައި ބަޔާންކޮށްފައިވާ ކުށް ސާބިތުކުރަނީ، އެ ކުށް ކުރި މީހާގެ އިޢުތިރާފު ނުވަތަ ހަތަރު ހެކީންގެ ހެކިބަހުން ނޫން ގޮތުގައި، ޑީ.އެން.އޭ އާއި ހައްޔަރުގައި އިނުމުގެ ޤަރީނާ ފަދަ އެކަށީގެންވާފަދަ ގޮތުގައި ޤަބޫލުކުރެވިދާނެ ފަދަ ޤަރީނާ ނުވަތަ ޤަރީނާތަކަކުން ކަމުގައި ވާނަމަ، އެ ކުށަކީ، އެނޫން ޙާލަތްތަކުގައި އެ ކުށް ދަރަޖަކުރެވޭ ނިސްބަތަށް ވުރެ އެއް ދަރަޖަ ތިރީގައިވާ ކުށެކެވެ.
