# Art. 58
58. ހުއްދަ ދިފާޢެއް ލިބިގެންވާކަމަށް ކުށްހީއެއްގައި ޤަބޫލުކުރެވުން -- ކުށްކުރި މީހާ އެ ކުށް ކުރީ އަންނަނިވި ޙާލަތުގައި ކަމަށް ވާނަމަ، އެ ކުރި ކުށަށް އޭނާއަށް މަޢާފުލިބިގެންވެއެވެ:
(ހ) މި ޤާނޫނުގެ 40 ވަނަ މާއްދާގައި ހުއްދަކުރެވިގެންވާ ދިފާޢުތަކުގެ ތެރެއިން ދިފާޢަކަށް އޭނާ ޢަމަލުކުރި ޙާލަތު، ފެތޭކަމުގައި އޭނާއަށް ޤަބޫލުކުރެވިގެންވުމާއި؛ އަދި
(ށ) އޭނާ ކުށްހީގެ ގޮތުގައި ހީކުރި ހީކުރުމަކީ:
(1) އޭނާގެ އިހްމާލެއް ނެތް ކަމެއްކަމަށް ވުމާއި؛ ނުވަތަ
(2) އޭނާ ކުށްހީގެ ގޮތުގައި ހީކުރި ހީކުރުމަކީ އެ ކުށާ ގުޅިގެން ބޭނުންވާ ކުށުގެ ނިޔަތުގެ މިންގަނޑުން ބަލާއިރު:
(i) އޭނާގެ މައްޗަށް އުފުލިގެންވާ ކުށުގެ ނަތީޖާގެ ރުކުނުގެ މިންގަނޑުން ކުށުގެ ނިޔަތް ކުޑަ ޢަމަލެއްކަމުގައި ވުމާއި؛ ނުވަތަ
(ii) ނަތީޖާގެ ރުކުނެއް އޭގައި ނުވާކަމަށް ވާނަމަ، ޙާލަތުގެ ރުކުނަށް ބަލާއިރުވެސް ނިސްބަތުން ކުޑަ ޢަމަލަކަށްވުން.
