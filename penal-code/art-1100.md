# Art. 1100
1100. ޢާންމު އުސޫލު
(ހ) މި ޤާނޫނުގެ ކުށް މާނަކުރާ މާއްދާތަކުގައި އަދަބު ކަނޑައެޅުމުގައި ރިޢާޔަތް ކުރަންޖެހޭ ކަންތައްތަކުގެ އަލީގައި އަދަބު ކަނޑައެޅުމުގެ އަސާސީ މިންގަނޑަށް ގެންނަންޖެހޭ ބަދަލުތަކުގެ އިތުރުން، މި ބާބުގައި ބަޔާންކޮށްފައިވާ މާއްދާތަކާ އެއްގޮތްވާ ގޮތުގެމަތިންވެސް އަދަބު ކަނޑައެޅުމުގެ އަސާސީ މިންގަނޑަށް ބަދަލު ގެންނަންވާނެއެވެ.
