# Art. 1205
1205. އިސްލާމީ ޝަރީޢަތުގައި ޙައްދު ކަނޑައަޅާފައިވާ ކުށްތައް
(ހ) މި ޤާނޫނުގައި އެހެން ގޮތަކަށް ބަޔާންކޮށްފައި ވީނަމަވެސް، އިސްލާމީ ޝަރީޢަތުގައި ޙައްދު ކަނޑައަޅާފައިވާ ނުވަތަ ޤިޞާޞް ކަނޑައަޅާފައިވާ ކުށެއް، އިސްލާމީ ޝަރީޢަތުގައި ކަނޑައެޅިފައިވާ ގޮތުގެމަތިން އެއްވެސް ޝައްކެއްނެތް މިންވަރަށް މީހެއްގެ މައްޗަށް ސާބިތުވެއްޖެނަމަ، އެމީހެއްގެ މައްޗަށް ކަނޑައަޅަންވާނީ އިސްލާމީ ޝަރީޢަތުގައިވާ ގޮތުގެމަތިން އެކަމަކަށް އިސްލާމީ ޝަރީޢަތުގައިވާ އަދަބެވެ.
(ށ) އެއްވެސް މީހެއްގެ މައްޗަށް މި މާއްދާގެ (ހ) ގައި ބަޔާންކޮށްފައިވާ އަދަބެއް ތަންފީޒުކުރަންވާނީ، އެ މައްސަލައެއްގެ ޝަރީޢަތުގެ ހުރިހާ މަރުޙަލާއެއް ނިމުމަށްފަހު ސުޕްރީމް ކޯޓުން އެ އަދަބެއް ދިނުމަށް ޙުކުމް ކޮށްފިނަމައެވެ.
(ނ) މި މާއްދާގެ (ހ) އާއި (ށ) ގައިވާ ގޮތުގެމަތިން އަދަބު ކަނޑައެޅޭ މީހެއްގެ އަދަބާމެދު ގޮތެއް ނިންމުމަށް، އިސްލާމީ ޝަރީޢަތުގައި ކަނޑައެޅިފައިވާ އިމުގެ ތެރެއިން ޙާކިމުގެ ހައިސިއްޔަތުން ރައީސުލްޖުމްހޫރިއްޔާއަށް ލިބިދީފައިވާ އިޚްތިޔާރު ބޭނުންކުރުމަކަށް މި މާއްދާ ހުރަހެއް ނާޅައެވެ.
(ރ) މި މާއްދާގެ ބޭނުމަށް "އިސްލާމީ ޝަރީޢަތް" ކަމުގައި ބުނެފައި އެވަނީ، ދިވެހިރާއްޖޭގެ ޖުމްހޫރިއްޔާގެ ޤާނޫނުއަސާސީ ގެ 274 ވަނަ މާއްދާގެ (ހ) ގައި "އިސްލާމީ ޝަރީޢަތް" އަށް ދީފައިވާ މާނަކުރުމެވެ.
