# Art. 1205
1205. ޤުރުއާނުގައި ޢުޤޫބާތް ކަނޑައެޅިފައިވާ ކުށްތައް -- ޤުރުއާނުގައި ޙައްދު ކަނޑައެޅިފައިވާ ކުށެއް، އިސްލާމީ ޝަރީޢަތުގައި ކުށް ސާބިތުވުމަށް އޮތް މިންގަނޑުކަމުގައިވާ އެއްވެސް ޝުބުހާއެއް ނެތް މިންވަރަށް މީހެއްގެ މައްޗަށް ސާބިތުވެއްޖެނަމަ، އެމީހަކަށް މި ޤާނޫނުގައިވާ ގޮތުގެމަތިން، ފަނޑިޔާރު ޙައްދުގެ އަދަބު ކަނޑައަޅަންވާނެއެވެ.
