# Art. 522 (unnumbered item 2)
ދަރަޖަކުރުން
(ނ)
(1) މި ގޮތުން ދެވޭ މަޢުލޫމާތަކީ އެ މަޢުލޫމާތުގެ ސަބަބުން މީހެއްގެ މައްޗަށް ޖިނާޔަތުގެ ކުށެއް ސާބިތުކުރެވިދާނެ ފަދަ މަޢުލޫމާތެއް ކަމުގައި ވާނަމަ:
(i) އަދި އެގޮތުން، ޖިނާޔަތުގެ 3 ވަނަ ދަރަޖައިގެ ނުވަތަ އެއަށްވުރެ މަތީ ދަރަޖައެއްގެ ކުށެއް ސާބިތުވެފައިވާނަމަ، އެ މަޢުލޫމާތު ދޭ މީހާ އެކުރަނީ ޖިނާޔަތުގެ 3 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(ii) އެނޫން ޙާލަތްތަކުގައި، އެއީ ޖިނާޔަތުގެ 5 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(ރ) މި މާއްދާގެ (ށ) ގައި ބަޔާންކޮށްފައިވާ ކުށަކީ ޖުނަޙްގެ 1 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
