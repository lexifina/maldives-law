# Art. 82 (unnumbered item 6)
ތަނާޒުލުވުމަކީ ނުވަތަ ރޭވުމެއް ދޫކޮށްލުމަކީ ދިފާޢަކަށް ނުވުން
(ކ) މި ޤާނޫނުގެ 85 ވަނަ މާއްދާ "ކުށެއް ކުރުމަށް އެއްބަސްވުމަށްފަހު އެކަން ދޫކޮށްލައި، ކުށުގެ ޢަމަލު ހިނގިޔަނުދިނުމުން ލިބޭ ދިފާޢު" ގައި ބަޔާންވެގެންވާ ޙާލަތުގައި މެނުވީ، ކުށެއް ކުރުމަށް ރޭވުމަށްފަހު އެ ކަމުން ތަނާޒުލުވުމަކީ ނުވަތަ އެކަން ދޫކޮށްލުމަކީ ދިފާޢެއް ނޫނެވެ.
