# Art. 1104 (unnumbered item 5)
ކުރީގެ ޤާނޫނުގެ ދަށުން ކޮށްފައިވާ ކުށްތައް
(ޅ) މި މާއްދާގެ ބޭނުމަށް، މި ޤާނޫނަށް ޢަމަލުކުރަން ފެށުމުގެ ކުރިން ކޮށްފައިވާ ކުށްތަކަކީ ޖިނާޔަތުގެ ކުށެއްކަން ނުވަތަ ޖުނަޙްގެ ކުށެއްކަން ކަނޑައަޅާނީ މި ޤާނޫނުގެ 91 ވަނަ މާއްދާ (ދަރަޖަ ކޮށްފައިނުވާ ކުށްތައް) ގައިވާ ގޮތުގެމަތިންނެވެ.
