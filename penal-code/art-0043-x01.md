# Art. 43 (unnumbered item 1)
މަރުވެދާނެ ފަދަ ގޮތަކަށް ނުވަތަ ބޮޑެތި ޖިސްމާނީ އަނިޔާދެވިދާނެ ފަދަ ގޮތަކަށް ބާރުގެ ބޭނުންކުރުން
(ށ) މީހަކު މަރުވެދާނެ ފަދަ ގޮތަކަށް، ނުވަތަ މީހަކަށް ބޮޑު ޖިސްމާނީ އަނިޔާ ލިބިދާނެ ފަދަ ގޮތަކަށް، ބާރުގެ ބޭނުންކުރުން، މި މާއްދާގެ (ހ) ގައި ބަޔާންކޮށްފައިވާ ޙާލަތްތަކުގައި ހުއްދަކުރެވިގެންވާނީ، އެ ޢަމަލަކީ އެހެން ބަޔަކު މަރުވެގެންދިއުން ނުވަތަ އެހެން ބަޔަކަށް ބޮޑެތި ޖިސްމާނީ އަނިޔާތައް ލިބިގެންދިއުން ހުއްޓުވުމަށްޓަކައި ކުރެވޭ ޢަމަލެއްކަމުގައި އެ ޢަމަލުވާނަމައެވެ.
