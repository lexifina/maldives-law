# Art. 1202 (unnumbered item 1)
ގޭގައި ބަންދުކުރުން
(ށ) ކުށްވެރިޔާގެ މައްޗަށް ކަނޑައެޅޭ އަދަބުގެ ބައެއް، ގޭގައި ބަންދުކޮށްގެން އެކަށީގެންވާ ގޮތެއްގައި ފުރިހަމަ ކުރެވޭނެކަމަށް އަންނަނިވި ޙާލަތުތަކުގައި ބެލޭނެއެވެ.
(1) ކުށްވެރިޔާއަކީ މުޖްތަމަޢަށް ނުރައްކާތެރި މީހެއްކަމަށް ނުވުން، އަދި
(2)
(I) ގޭގައި ހުރެގެން އޭނާގެ ޢާއިލާއަށް ބޭނުންތެރި މިންވަރަކަށް އެހީތެރިކަން ފޯރުކޮށްދެވުން، ނުވަތަ
(II) ކުށްވެރިޔާއަށް ބޭނުންވާ ވަކި ޚާއްޞަ ކަންތައްތަކެއް އޭނާގެ ގޭގައި ކުރެވެންހުރުން.
