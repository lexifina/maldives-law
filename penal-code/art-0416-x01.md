# Art. 416 (unnumbered item 1)
ގެއްލުމެއް ލިބިދާނެ ކަމުގެ ބިރު އުފެދޭ މައިން އިސްތިސްނާވެގެންވުން
(ށ) މި މާއްދާގެ (ހ) ގައި ބަޔާން ކޮށްފައިވާ ޢަމަލު އަންނަނިވި ޙާލަތްތަކުގައި ކުށެއްކަމަކަށް ނުބެލެވޭނެއެވެ:
(1) ކުށުގެ ޢަމަލު ކުރާ މީހަކީ:
(i) މަންމަޔަކަށްވުން؛ ނުވަތަ
(ii) ހުއްދަލިބިގެންވާ ޞިއްޙީ މަސައްކަތް ތެރިއަކަށްވުން؛ އަދި
(2) އެގޮތަށް ހައްޔަރުގައި އިނުމުގެ ސަބަބުން ހައްޔަރުގައި އިން އަންހެނާގެ ފުރާނައަށް ގެއްލުން ލިބިދާނެކަމަށް، ހުއްދަ ލިބިގެންވާ ޞިއްޙީ މަސައްކަތްތެރިއަކު ކަނޑައަޅާފައިވުން.
