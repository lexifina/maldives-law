# Art. 313
313. ކުށް މާނަކުރުން
(ހ) މުދަލަކާ ނުވަތަ ޚިދުމަތަކާ ގުޅޭގޮތުން ކުރުމަށް ހުށަހެޅިފައިވާ ނުވަތަ ފުރިހަމަ ކުރެވިފައިވާ މުޢާމަލާތަކާ ގުޅިގެން، އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ.
(1) ޞައްޙަ ނޫން މަޢުލޫމާތު ނުވަތަ ކަމެއް އޮޅިގެން ހިނގައިދާނެފަދަ މަޢުލޫމާތު، ފަރުވާލެއްނެތި ދިނުން؛ ނުވަތަ
(2) ވިޔަފާރީގައި ޢާންމުކޮށް ޢަމަލުކުރެވޭ ކަމަށް ޤަބޫލު ކުރެވިފައިވާ އުސޫލުތަކާއި މިންގަނޑުތަކާ ކަނޑައެޅިގެން ޚިލާފަށް، ޢަމަލެއް ކޮށްގެން، އެނގިހުރެ، މީހަކަށް ކަމެއް އޮޅުވާލުން.
