# Art. 50 (unnumbered item 1)
މަޢާފު ލިބެނިވި ދިފާޢެއްގެ ޙައްޤު އޮތް މީހެއްގެ ޢަމަލު ހުއްޓުވުން
(ށ) މި ޤާނޫނުގައި އެހެންގޮތަކަށް ބަޔާންކޮށްފައި ނުވާހާހިނދަކު، މީހަކު ކުރާ ހުއްދަނޫން ޢަމަލެއްގެ ސަބަބުން އޭނާއަށް މަޢާފު ލިބިދެވޭ ލިބިދިނުމަކީ، ޤާނޫނު ހުއްދަކުރާ ގޮތެއްގެމަތިން، އޭނާއަށް ނުދީ ހިފެހެއްޓިދާނެ ދިފާޢެކެވެ.
