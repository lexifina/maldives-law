# Art. 56 (unnumbered item 1)
އިޖްތިމާޢީ މިންގަނޑުތަކާ ދެކޮޅު ޝަޚްޞުތައް އެކަހެރި ކުރެވިގެންވުން
(ށ) މި މާއްދާގެ (ހ) ގެ ބޭނުމަށްޓަކައި ކަށަވަރުކުރެވިދާނެ ބައްޔެއް ނުވަތަ ނުކުޅެދުމެއްކަމުގައި ބެލެވޭ ކަންކަމުގެ ތެރޭގައި، ހަމައެކަނި ތަކުރާރުކޮށް ކުށްކުރާ ކުށްވެރިންނާއި، ޢާންމު އިޖްތިމާޢީ މިންގަނޑުތަކާ ދެކޮޅު ޢަމަލުތައް ހިންގާ މީހުންކަމުގައި ބެލެވޭ މީހުންގެ ކިބައިން ފެންނަ ސިކުނޑީގެ ޙާލަތުތައް ހިމެނިގެނެއްނުވެއެވެ.
