# Art. 24 (unnumbered item 8)
ކުށުގެ ޒިންމާ އުފުލުމަށް ކުށުގެ ޢަމަލު އެކަނި ފުދޭ ޙާލަތު
(ވ) ކުށުގެ މަޤްޞަދުގެ ރުކުނަކާ ގުޅޭ ގޮތުން ޒިންމާ އުފުލުމަށް ކުށުގެ ޢަމަލު އެކަނި ފުދޭ ޙާލަތުގައި، މި މާއްދާގެ (އ) ގައި ބަޔާންކޮށްދީފައިވާ ފަދައިން ކުށުގެ ނިޔަތް ސާބިތުވުމަކީ، އަންނަނިވި ކުށްކުށް ސާބިތުކުރުމުގައި ބޭނުން މިންގަނޑެއް ނޫނެވެ:
(1) ކުރި ކުށަކީ މުޚާލަފާތުގެ ތެރޭގައި ހިމެނޭ ކަމެއް ކަމުގައިވުން؛ ނުވަތަ
(2) އެ ކުށަކީ މި ޤާނޫނު ނޫން އެހެން ޤާނޫނެއްގައި ކަނޑައެޅިފައިވާ ކުށަކަށް ވުމާއި، އެ ކުށް ކަނޑައެޅުމުގައި ޤާނޫނުގެ މަޤްޞަދަކީ، ކުށުގެ ނިޔަތް ސާބިތުކުރަން ނުޖެހޭ ގޮތަށް، ކުށުގެ އެހެން މައިގަނޑު ރުކުނެއް އެކަނި ސާބިތުވުންކަން، އެ ކުށް ކަނޑައެޅި ޤާނޫނުން ސާފުކޮށް ދޭހަވާން އޮތުން.
