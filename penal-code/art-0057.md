# Art. 57
57. ލިބެންނެތް ޤާނޫނެއްގެ ސަބަބުން ކަމެއް އެނގިގެންނުވުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި ކުރެވޭ ކުށަށް، އެ ކުށްކުރި މީހާއަށް މަޢާފުލިބިގެންވެއެވެ:
(1) ކުށްކަމުގައި ބެލެވޭ ޢަމަލު ހިންގުމުގެ ކުރިން އެ ކުށް ކަނޑައަޅާފައިވާ ޤާނޫނު އޭނާއަށް އެނގިފައި ނެތުމާއި، އަދި އެ ޤާނޫނަކީ ޝާއިޢުކުރެވިފައިވާ ޤާނޫނަކަށް ނުވުން ނުވަތަ އޭނާއަށް އެ ލިބޭނެ ނުވަތަ ފެންނާނެ ގޮތެއް އެކަށީގެންވާ ގޮތެއްގައި ހަމަޖެއްސިފައިވާ ޤާނޫނަކަށް ނުވުން.
(2) އަދި، މި މާއްދާގެ (ހ) ގެ 1 ގައިވާ ކަންކަމުގެ ނަތީޖާއެއްގެ ގޮތުން، އެ ކުށް ކުރި ވަގުތުގައި އޭނާގެ އެ ޢަމަލަކީ ޤާނޫނުގައި މަނާވެގެންވާ ޢަމަލެއްކަން އޭނާއަށް އެނގިފައިނުވުން.
