# Art. 711
711. ކުށް ކަނޑައެޅުން
(ހ) ލައިސަންސެއްނެތި ނުވަތަ ސަރުކާރުގެ ސީދާ ހުއްދައެއްނެތި، އަންނަނިވި ޢަމަލުތަކުގެ ތެރެއިން ޢަމަލެއް އެނގިހުރެ ކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) ފަނާކުރަނިވި މާއްދާއެއް ހިމެނޭ އެއްޗެއް އުފެއްދުމާއި، ގެންގުޅުމާއި، ވިއްކުމާއި، އެހެން މީހަކަށް ދިނުމާއި އެހެން ތަނަކަށް ގެންދިއުމާއި އެއިން ވިޔަފާރިކުރުން؛ ނުވަތަ
(2) ބަޑި އުފެއްދުމާއި އެއިން ވިޔަފާރިކުރުން؛ ނުވަތަ
(3) އެހެން މީހަކަށް ބަޑިއެއް ދިނުން ނުވަތަ އެހެން މީހަކަށް ބަޑިއެއް ވިއްކުން؛ ނުވަތަ
(4) ބަޑިއެއް ގެންގުޅުން.
