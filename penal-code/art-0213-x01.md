# Art. 213 (unnumbered item 1)
އިސްތިސްނާ ޙާލަތް
(ށ) މީހަކު މުދަލެއް ހޯދީ އަންނަނިވި ސަބަބުތަކުގެ ތެރެއިން ސަބަބަކަށްޓަކައި، އަނބުރާ ހޯދަން ޖެހިފައިވާ މުދާކަމުގައި ނުވަތަ ގެއްލުމުގެ ބަދަލުގައި ހޯދި މުދާ ކަމަށް، އިޚްލާޞްތެރިކަމާއެކު ދެކެގެންކަމުގައިވާނަމަ، އޭނާ ކުރި ޢަމަލަކީ، ކުށެއް ނޫނެވެ:
(1) އެ މުދާ ހޯދި ޙާލަތާ ސީދާ ގުޅުން ހުރި ގޮތުގައި، އޭނާއަށް ލިބިފައިވާ ގެއްލުމަކަށްޓަކައި ކަމުގައިވުން؛ ނުވަތަ
(2) ޤާނޫނީ ގޮތުން ހުއްދަ މުޢާމަލާތެއްގެ ދަށުން އޭނާއަށް ލިބެން ޖެހޭ މުދަލެއް ނުވަތަ ދަރަނީގެ ފައިސާއެއްގެ ބަދަލުގައިކަމުގައިވުން.
