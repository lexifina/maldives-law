# Art. 312 (unnumbered item 1)
ކާކުކަން އަންގައިދޭ ލިޔުމުގެ ގޮތުގައި ހިމެނޭ މަޢުލޫމާތު
(ށ) މި މާއްދާގެ (ހ) ގެ (2) ވަނަ ނަންބަރުގެ (ii) ގެ ބޭނުމަށްޓަކައި އަދި މި މާއްދާގެ (ހ) ގެ (2) ވަނަ ނަންބަރުގެ (iii) ގެ ބޭނުމަށްޓަކައި ކާކުކަން އަންގައިދޭ މަޢުލޫމާތުގެ ތެރޭގައި، މީހެއްގެ ނަމާއި، އުފަން ތާރީޚާއި، އޭނާއަށް ދޫކުރެވިފައިވާ އައިޑެންޓިފިކޭޝަން ނަންބަރާއި، ކޯޑާއި، އޭނާގެ މާލީ މަޢުލޫމާތާއި، ވަކި މީހަކު ދެނެގަތުމަށްޓަކައި ބޭނުންކުރެވިދާނެ އެހެން ކޮންމެ މަޢުލޫމާތެއް ހިމެނެއެވެ.
