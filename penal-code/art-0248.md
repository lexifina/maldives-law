# Art. 248
248. ކުށް ކަނޑައެޅުން
(ހ) އެނގިހުރެ، އަންނަނިވި ޙާލަތްތަކުގައި އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ.
(1) ހުއްދަނެތި ކޮމްޕިއުޓަރ ޑޭޓާއެއް އިންޕުޓްކުރުން ނުވަތަ އޮލްޓަރކުރުން ނުވަތަ ޑިލީޓްކުރުން ނުވަތަ ސަޕްރެސްކުރުން ނުވަތަ ކޮމްޕިއުޓަރ ސިސްޓަމެއްގެ ފަންކްޝަންކުރުމަށް އެއްވެސް ބާވަތެއްގެ އިންޓަރފިއަރެންސެއް ހިންގުމާއެކު، އޭގެ ސަބަބުން މީހަކަށް ގެއްލުމެއް ލިބުމަށް މެދުވެރިކުރުވުން؛
(2) އަދި އެ ޢަމަލު ހިންގާފައިވަނީ، ހުއްދަނޫން އިޤްތިޞާދީ ފައިދާއެއް ނުވަތަ އަގުކުރެވޭ ނުޙައްޤު މަންފާއެއް އޭނާއަށް ނުވަތަ އެހެން މީހަކަށް ހޯދުމުގެ މަކަރުވެރި ނިޔަތުގައި ނުވަތަ ނުރަނގަޅު ނިޔަތުގައި ކަމަށްވުން.
