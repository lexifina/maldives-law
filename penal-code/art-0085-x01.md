# Art. 85 (unnumbered item 1)
އަމިއްލަ އިޚްތިޔާރުގައި ފުރިހަމައަށް ދޫކޮށްލާ ދޫކޮށްލުމަކަށްވުން
(ށ) ކުށެއްގެ މަޤްޞަދު އަންނަނިވި ޙާލަތްތަކުގައި ދޫކޮށްލާ ދޫކޮށްލުމަކީ އަމިއްލަ އިޚްތިޔާރުގައި ފުރިހަމައަށް ދޫކޮށްލި ދޫކޮށްލުމެއް ކަމުގައެއް ނުބެލެވޭނެއެވެ:
(1) އެކަން ދޫކޮށްލީ އަންނަނިވިފަދަ ޙާލަތެއް އޮތްކަމަށް ޤަބޫލުކުރެވިގެން ކަމަށްވުން؛
(i) އެ ކުށް ކުރާ ކަން އެނގިދާނެކަމުގެ ނުވަތަ އެ ކުށް ކުރަނިކޮށް ހައްޔަރުވެދާނެކަމުގެ ނުވަތަ އެ ކުށުގައި ބައިވެރިވާ އެހެން މީހަކު ހައްޔަރުކޮށްފާނެކަމަށް ޤަބޫލުކުރެވޭނެ ފަދަ ޙާލަތެއް އޮވެގެންކަމުގައިވުން؛ ނުވަތަ
(ii) އެ ކުށް ކުރުން އިތުރަށް އުނދަގޫވާ ފަދަ ޙާލަތެއް ކުރިމަތިވެގެން ކަމުގައިވުން.
(2) އެކަން ދޫކޮށްލީ އަންނަނިވި ފަދަ ނިންމުމަކާ ގުޅިގެން ކަމުގައިވުން:
(i) އެ ކުށް ކުރުން އެހެން ވަގުތަކަށް ލަސްކުރަން ނިންމުމަށް ފަހުގައިކަމުގައިވުން؛ ނުވަތަ
(ii) އެހެން މީހަކާ މެދު އެ ކުށް ކުރުމަށް ނިންމުމަށް ފަހުގައިކަމުގައިވުން ނުވަތަ އެ ކުށުގެ މަޤްޞަދާ އެއްފަދަ އެހެންނަމަވެސް ތަފާތު މަޤްޞަދެއް ހާޞިލުކުރުމަށް ނިންމުމަށް ފަހުގައިކަމުގައިވުން.
