# Art. 412 (unnumbered item 2)
މާނަކުރުން
(ނ) "ހުއްދަނޫން ޖިންސީ މުޢާމަލާތް" ކަމަށް ބުނެފައި އެވަނީ، ތިމާއާ އެއް ޖިންސުގެ މީހަކާއެކު ނުވަތަ ތިމާ އިނދެގެންއުޅޭ މިހާ ފިޔަވައި، އެހެން މީހަކާއެކު ނުވަތަ ޖަނަވާރަކާއެކު ޖިންސީ އަރާމެއް ހޯދުމުގެ ބޭނުމުގައި، މި ޤާނޫނުގެ 411 ވަނަ މާއްދާގެ (ހ) ގައި ބަޔާންކޮށްފައިވާ ދެ ކުށަށް ނުހިމެނޭ ގޮތުން ހިންގާ ބަދު އަޚްލާޤީ ޢަމަލުތަކަށެވެ.
