# Art. 40 (unnumbered item 5)
އެއް ދިފާޢަށް ވުރެ ގިނަ ދިފާޢުގެ ބޭނުންހިފުން
(ބ) މި މާއްދާގެ (ޅ) ގައި ބަޔާންކޮށްފައިވާ ޙާލަތުގައި މެނުވީ، މީހެއްގެ ޢަމަލަކާ ގުޅިގެން ހުއްދަވެގެންވާ ދިފާޢުގެ އެއް ދިފާޢަށްވުރެ ގިނަ ދިފާޢު ބޭނުންކުރެވޭ ފަދަ ޙާލަތެއް ދިމާވެއްޖެނަމަ، އެ ހުރިހާ ދިފާޢަކީވެސް އޭނާއަށް ބޭނުންކުރެވިދާނެ ދިފާޢެވެ.
