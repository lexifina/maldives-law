# Art. 23 (unnumbered item 1)
ޤާނޫނު ހުއްދަ ނުކުރާ ގޮތެއްގެ މަތިން، އަތުގައި އެއްޗެއް ބެހެއްޓުން
(ށ) އަތުގައި އެއްޗެއް ބަހައްޓައިގެން މީހަކު ކުށުގެ ޒިންމާ އުފުލަންޖެހޭނީ އެ މީހަކަށް އެނގިހުރެ، އަންނަނިވި ކަންކަމުންކުރެ ކަމެއް އޭނާ ކުރާ ޙާލަތުގައި، އެކަންޏެވެ.
(1) އަތުގައި އެއްޗެއް އޮވެ އެ އެއްޗަކީ އޭނާ ހޯދި، ނުވަތަ އޭނާ ބަލައިގަތް އެއްޗަކަށްވުން؛ ނުވަތަ
(2) އަތުގައި އެއްޗެއް އޮވެ އެ އެއްޗެއް އަތުން ދޫކޮށްލުމަށް އެކަށީގެންވާ ވަގުތު ލިބިމެ، އެ އެއްޗެއް އޭނާގެ އަތުގައި އޮތުން.
