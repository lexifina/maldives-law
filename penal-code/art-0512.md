# Art. 512
512. ކުށް ކަނޑައެޅުން
(ހ) ދައުލަތުގެ މުވައްޒަފަކަށްހުރެ ރަސްމީ ހައިސިއްޔަތުން އޭނާގެ ވާޖިބު އަދާކުރުމުގައި އެނގިހުރެ އަންނަނިވި ޢަމަލުތަކުން ޢަމަލެއް ކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) ޤާނޫނުގައިވާ ގޮތުގެމަތިން އަދާކުރަން ޖެހޭ ވާޖިބެއް އަދާނުކޮށް ދޫކޮށްލުން؛ ނުވަތަ
(2) ޤާނޫނުގައި ހުއްދަކޮށްފައިނުވާ ކަމެއް ކުރުން.
