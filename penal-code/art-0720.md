# Art. 720
720. ކުށް ކަނޑައެޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) ކުށްކުރާ ޖަމާޢަތެއް ހިންގުމުގައި ބައިވެރިވުން؛ ނުވަތަ
(2) ކުށްކުރާ ޖަމާޢަތެއް ހިންގުމުގައި ބައިވެރިކުރުމަށް މީހަކު އެ ޖަމާޢަތާ ގުޅުވުން؛ ނުވަތަ
(3) ކުށްކުރާ ޖަމާޢަތަކަށް މާއްދީ ގޮތުންނާއި މާލީގޮތުން އެހީތެރިވެދިނުން؛ ނުވަތަ
(4) ކުށްކުރާ ޖަމާޢަތެއްގެ ޙަރަކާތްތަކުން ލިބޭ ފައިސާ ބޭނުންކުރުމާއި އެހެން ކަމެއްގައި އެ ފައިސާ އިންވެސްޓުކުރުން؛ ނުވަތަ
(5) ކުށްކުރާ ޖަމާޢަތެއްގެ ޙަރަކާތްތައް އެއްވެސް ގޮތަކުން ކޮންޓްރޯލުކުރުމާއި، އެޙަރަކާތްތައް ކުރިއަށް ގެންދަންވީގޮތުގެ އިރުޝާދު ދިނުން.
