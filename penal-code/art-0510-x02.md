# Art. 510 (unnumbered item 2)
މާނަކުރުން
(ނ) "ރަސްމީ ހައިސިއްޔަތު" ކަމަށް ބުނެފައި އެވަނީ ދައުލަތުގެ މުވައްޒަފަކު، ރަސްމީ ގޮތުން އަދާކުރަން ޖެހޭ ދައުލަތުގެ ވާޖިބެއްގެ ދަށުން ކުރާ ކަންކަމަށާއި ނުކޮށް ދޫކޮށްލާ ކަންކަމަށެވެ. ނުވަތަ ވަކި މީހަކަށް ނުވަތަ ވަކި ބަޔަކަށް މަންފާއެއް ދިނުމަށް ނުވަތަ ނުދިނުމަށް ދައުލަތުގެ މުވައްޒަފަކަށް، ލިބިދޭ ބާރުގެ ބޭނުންކުރުމަށާއި ބޭނުންނުކުރުމަށެވެ.
