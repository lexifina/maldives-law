# Art. 71
71. ކުންފުންޏަކާ ނުވަތަ ޖަމާޢަތަކާ ގުޅުމެއް އޮތުމަކީ ފަރުދީ ޒިންމާ އުފުލުމަށް އޮތް ހުރަހަކަށް ނުވުން
(ހ) ކުންފުންޏެއްގެ ނަމުގައި ނުވަތަ ކުންފުނީގެ ގޮތުގައި ރަޖިސްޓަރީކޮށްފައިވާ ޖަމާޢަތެއްގެ ނަމުގައި މީހަކު ކުރާ ނުވަތަ ކުރުވާ ކުށުގެ ޢަމަލަކީ، އޭނާގެ އަމިއްލަ ފަރުދީ ހައިސިއްޔަތުންވެސް ޒިންމާ އުފުލަންޖެހޭނެ ޢަމަލެކެވެ.
(ށ) ކުންފުންޏަކުން ނުވަތަ ކުންފުނީގެ ގޮތުގައި ރަޖިސްޓަރީކޮށްފައިނުވާ ޖަމާޢަތަކުން ކޮށްފައިވާ ކުށެއްގެ ޒިންމާ އުފުލަން ޖެހިފައިވާ މީހަކަށް، ވަކިފަރުދަކު އެފަދަ ކުށެއްކޮށްފިނަމަ ދެވޭނެކަމަށް ޤާނޫނުގައި ކަނޑައަޅާ އަދަބު ދެވޭނެއެވެ. އަދި އެއީ އެ ކުންފުންޏަށް ނުވަތަ އެ ޖަމާޢަތަށް އެހެން އަދަބެއް ކަނޑައެޅިފައި ވީނަމަވެހެވެ.
