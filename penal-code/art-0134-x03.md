# Art. 134 (unnumbered item 3)
އަދަބު ކަނޑައެޅުމުގައި ބަލަން ޖެހޭ ނުކުތާ
(ރ) މި މާއްދާގައި ބަޔާންކޮށްފައިވާ ކުށެއް ކުރުމުގައި، އެ ކުށްކުރާ މީހާ އޭނާގެ ޢަމަލުތަކުގެ ޒާތާގުޅޭ ގޮތުން ނުވަތަ އޭނާގެ ޝަޚްޞާގުޅޭ ގޮތުން އޮޅުވާލުމެއް އޮޅުވާލާފައިވާނަމަ އަދި އެގޮތަށް އޮޅުވާލީ އެ ކުށްކުރުމުގެ މަޤްޞަދުގައިކަމަށްވާނަމަ، އޭނާއަށް ދެވޭ އަދަބު އެކަމަށް ކަނޑައެޅިފައިވާ އަދަބުގެ އެންމެ އަސާސީ މިންގަނޑަށްވުރެ އެއް ދަރަޖަ މަތިވެގެންވެއެވެ.
