# Art. 220 (unnumbered item 3)
ދަރަޖަކުރުން
(ރ) މި ކުށަކީ؛
(1) ލިބުނު ގެއްލުމުގެ އަގު -/500,000 ރުފިޔާއަށް ވުރެ މަތިވާ ކަމުގައިވާނަމަ، ޖިނާޔަތުގެ 4 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(2) ލިބުނު ގެއްލުމުގެ އަގު -/50,000 ރުފިޔާއަށް ވުރެ މަތިވާ ކަމުގައި ވާނަމަ، ޖިނާޔަތުގެ 5 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(3) ލިބުނު ގެއްލުމުގެ އަގު -/5,000 ރުފިޔާއަށްވުރެ މަތިވާނަމަ، ޖުނަޙްގެ 1 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(4) ލިބުނު ގެއްލުމުގެ އަގު -/500 ރުފިޔާއަށް ވުރެ މަތިވާނަމަ، ޖުނަޙްގެ 2 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(5) އެނޫން ޙާލަތްތަކުގައި އެ ކުށަކީ ޖުނަޙްގެ 3 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
