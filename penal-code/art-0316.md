# Art. 316
316. ކުށް ކަނޑައެޅުން
(ހ) ރަހުނުގެ ގޮތުގައި ބެހެއްޓިފައިވާ މުދަލުގެ މައްޗަށް އަދާކުރަން ޖެހޭ ރަހުނުގެ ދަރަނި އަދާކުރުމަށް ހުރަސްއެޅުމުގެ ނިޔަތުގައި، ރަހުނުގެ ގޮތުގައި ބެހެއްޓިފައިވާ މުދަލެއް ނައްތާލައިފިނަމަ، ނުވަތަ ހުރި ތަނުން ގެންގޮސްފިނަމަ، ނުވަތަ ފޮރުވައިފިނަމަ، ނުވަތަ އޭގެ މައްޗަށް އިތުރު ޙައްޤެއް އުފައްދައިފިނަމަ، ނުވަތަ އޭގެ މިލްކުވެރިކަން ބަދަލުކޮށްފިނަމަ، ނުވަތަ އެނޫންވެސް ގޮތަކުން އެއިން މުޢާމަލާތެއް ކޮށްފިނަމަ، އެކުރަނީ ކުށެކެވެ.
