# Art. 412 (unnumbered item 1)
މާނަކުރުން
(ށ) "ޖިންސީ މުޢާމަލާތް" ކަމަށް ބުނެފައި އެވަނީ، އެހެން މީހެއްގެ ޖިންސީ ގުނަވަނެއްގައި ނުވަތަ ޖިންސީ އަރާމެއް ހޯދައިގެނެވޭ ހިސާބެއް ކަމަށް ބެލެވޭ ތަނެއްގައި އަތްލުމަށް ނުވަތަ އަތްލެއްވުމަށް ނުވަތަ އެއްޗެއް މެދުވެރިކޮށް އަތްލުމަށް ނުވަތަ އަތްލެއްވުމަށް ނުވަތަ ބީހުމަށެވެ.
