# Art. 57 (unnumbered item 2)
އެކަށީގެންވާ ފަރުވާތެރިކަމާއެކު ޢަމަލުކުރިކަމުގައި ވީނަމަވެސް ޤާނޫނު އޮތް ގޮތާ މެދު ކުށްހީއެއް ކުރެވުން
(ނ) ކުށުގެ ޢަމަލުކަމުގައި ބެލެވޭ ޢަމަލު ހިންގި ވަގުތު އޭނާ އެ ޢަމަލު ކުރީ އަންނަނިވި ޙާލަތްތަކުގައިކަމަށް ވާނަމަ އޭނާ އެ ކުރި ކުށަށް އޭނާއަށް މަޢާފުލިބިގެންވެއެވެ.
(1) އޭނާއަކީ:
(i) އޭނާގެ ޢަމަލުގެ މައްޗަށް އެ ކުށުގެ ދާއިރާ ހިނގާނެ މިންވަރު ދެނެގަތުމަށް އެކަށީގެންވާ ގޮތުގައި އެޅެން ހުރި ހުރިހާ ފިޔަވަޅެއް އެޅި މީހަކު ކަމުގައި ވުމާއި؛ އަދި
(ii) އޭނާގެ ޢަމަލަކީ ކުށެއް ނޫންކަމަށް އިޚްލާޞްތެރިކަމާއެކު ތެދުނިޔަތުގައި އޭނާ ޤަބޫލުކުރުމާއި، އަދި އެކަން ޤަބޫލުކުރި ޙާލަތަކީ ޤާނޫނަށް ފުރިހަމައަށް ތަބާވާ، ބުއްދިވެރި އެހެން ކޮންމެ މީހަކުވެސް، އެ ޙާލަތުގައި ޤަބޫލުކުރާނެ ގޮތްކަމަށް ބެލެވުން؛ އަދި
(2) އެކަމުގެ ނަތީޖާއެއްގެ ގޮތުން އެ ކުށް އޭނާ ކުރިއިރު އެއީ ޤާނޫނުގައި މަނާވެގެންވާ ޢަމަލެއްކަމުގައި އޭނާއަށް އެނގިފައިނުވުން.
