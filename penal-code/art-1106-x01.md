# Art. 1106 (unnumbered item 1)
ކުށަށް އިޢްތިރާފްވުން
(ށ) ކުށްވެރިޔާގެ މައްޗަށް ދަޢުވާ ކުރެވިފައި ވީނަމަވެސް އެ މައްސަލައިގެ ޝަރީޢަތް ނުފެށޭހާހިނދަކު، ކުށްވެރިޔާ އެ ކުރި ކުށަށް އިޢްތިރާފްވެއްޖެނަމަ، އޭނާގެ މައްޗަށް ކަނޑައަޅަންޖެހޭ އަދަބު، އަދަބު ކަނޑައެޅުމުގެ އަސާސީ މިންގަނޑަށްވުރެ 1 ދަރަޖަ ދަށްވާނެއެވެ.
