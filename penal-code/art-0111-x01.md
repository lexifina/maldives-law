# Art. 111 (unnumbered item 1)
ސިކުނޑިއަށް ނުވަތަ ޖަޒުބާތަށް އިންތިހާއަށް އަސަރުކޮށްފައިވާ ޙާލަތްތަކުގައި މެރުމުގެ ކުށަކަށް ނުވުން
(ށ) މި ޤާނޫނުގެ 110 ވަނަ މާއްދާގެ ދަށުން މީހަކު މެރުމުގެ ކުށް ކަމުގައި ބެލެވޭ ޢަމަލެއް މީހަކު ކުރި ނަމަވެސް، އަންނަނިވި ޙާލަތްތަކުގައި އެއީ މި ޤާނޫނުގެ 111 ވަނަ މާއްދާގެ (ހ) ގައި ބުނެފައިވާ ކުށް ކަމުގައި ބަލަންވާނެއެވެ:
(i) އޭނާ، އެ ޢަމަލު ހިންގާފައިވަނީ، އޭނާގެ ސިކުނޑިއަށް ނުވަތަ ޖަޒުބާތަށް އިންތިހާއަށް އަސަރުކޮށްފައިވާ ދަނޑިވަޅެއްގައި، އެކަމުގެ ނުފޫޒުގައިހުރެ ކަމުގައިވުން؛
(ii) އެ ކުރި ޢަމަލަށް އެކަށީގެންވާ ސަބަބެއް އޮތުމާއި، އެސަބަބުގެ އެކަށީގެންވާކަން އެ ޢަމަލު ހިންގާ މީހާ ހުރިކަމަށް ޤަބޫލުކުރެވޭ ޙާލަތުގައި ހުންނަ އެހެން މީހެއްގެ ނަޒަރުން ކަނޑައެޅިގެން ދިޔުން.
