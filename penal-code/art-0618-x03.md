# Art. 618 (unnumbered item 3)
އެހެންގޮތަކަށް ސާބިތުނުވާހާހިނދަކު ވަކި ގޮތަކަށް ޤަބޫލުކުރުން
(ރ) އެހެން ގޮތަކަށް ސާބިތުނުވާހާހިނދަކު އަންނަނިވި ޢަމަލުތައް މީހެއްގެ ފަރާތުން ފެނިފައިވާނަމަ އެހީތެރިކަމަށް ބޭނުންވެފައިވާ މީހަކަށް އެހީތެރިކަން ފޯރުކޮށްނުދިންކަމަށް، ފަނޑިޔާރު ޤަބޫލުކުރަންވާނެއެވެ.
(1) މަސައްކަތްކުރާ ޓެލެފޯނެއް ނުވަތަ ރޭޑިޔޯއެއް އޭނާގެ ކޮންޓްރޯލުގައި އޮވެ، ނުވަތަ އެއިން އެއްޗެއް އޭނާއަށް ލިބޭ ހިސާބުގައިވާކަން އެނގިހުރެ؛
(2) އެހީތެރިކަމަށް ބޭނުންވެފައިވާ މީހާއަށް އެހީތެރިވުމަށްޓަކައި ޞިއްޙީ މަސައްކަތްތެރިންނަށް ނުވަތަ ޤާނޫނު ތަންފީޒުކުރާ އިދާރާގެ މީހުންނަށް އަންގާފައިވާކަމަށް ޤަބޫލުކުރާނެ ސަބަބެއް ނެތި؛
(3) އެ ކުއްލި ނުރައްކަލުގެ ޙާލަތާ ގުޅޭ ގޮތުން ޞިއްޙީ މަސައްކަތްތެރިންނަށް ނުވަތަ ޤާނޫނު ތަންފީޒުކުރާ އިދާރާއަށް އެކަން އަންގާފައިނުވުން.
