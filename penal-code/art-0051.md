# Art. 51
51. އަމިއްލަ އިޚްތިޔާރުގައި ނޫން ގޮތަކަށް ކުރެވޭ ޢަމަލު އަދި އަމިއްލަ އިޚްތިޔާރުގައި ނޫން ގޮތަކަށް ނުކޮށް ދޫކޮށްލެވޭ ޢަމަލު -- މީހަކު ކުރި ކުށެއްގެ ޒިންމާ އެ މީހަކު އުފުލަންޖެހެނީ އަންނަނިވި ޙާލަތްތަކުގައިކަމަށް ވާނަމަ، އެ ކުށަކަށް އެ މީހަކަށް މަޢާފުލިބިގެންވެއެވެ:
(ހ) އޭނާ ކުރި ޢަމަލަކީ، އެ ޢަމަލުކުރުމަށް އޭނާގެ އަމިއްލަ އިޚްތިޔާރުގައި ނުވަތަ އަމިއްލަ ވިސްނުމުގައި ކަނޑައަޅައިގެން ކުރި ޢަމަލަކަށް ނުވުން؛ ނުވަތަ
(ށ) އޭނާ ނުކޮށް ދޫކޮށްލި ކަމަކީ، ސިކުނޑީގެ ގޮތުން ނުވަތަ މާއްދީ ގޮތުން އޭނާ ކުރުމަށް ނުކުޅެދިގެންވާ ކަމަކަށްވުން، ނުވަތަ ނުކޮށް ދޫކޮށްލި ޢަމަލު ކުރުމަކީ އޭނާހުރި ޙާލަތުގެ ގޮތުން އޭނާގެ ކިބައިން އެކަށީގެންވާ ގޮތުގައި އުންމީދުކުރެވޭ ކަމެއްކަމުގައި ނުވުން.
