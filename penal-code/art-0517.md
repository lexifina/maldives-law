# Art. 517
517. ކުށް ކަނޑައެޅުން
(ހ) ދައުލަތުގެ މުވައްޒަފަކު، އޭނާގެ ރަސްމީ ވާޖިބު އަދާކުރުމުގައި، އެނގިހުރެ އަދި އެކަށީގެންވާ ސަބަބެއް ނެތި، އަންނަނިވި ޙާލަތްތަކުގައި އެކުރަނީ ކުށެކެވެ.
(1) ދައުލަތަށް ފައިދާއެއް ލިބެންއޮތް ކަމެއްގެ ފައިދާ ދައުލަތަށް ނުލިބޭގޮތަކަށް ޢަމަލުކުރުން؛ ނުވަތަ
(2) ދައުލަތަށް ލިބެންއޮތް ފައިދާއަކަށް އުނިކަމެއް ލިބޭގޮތަށް ޢަމަލުކުރުން.
