# Art. 15 (unnumbered item 2)
ދަޢުވާކުރާ ފަރާތުގެ މައްޗަށް އޮތް ޒިންމާ
(2) މި ޤާނޫނުގައި ކަނޑައެޅިގެން އެހެން ގޮތަކަށް ބަޔާންކޮށްފައި ނުވާހާހިނދަކު، އަންނަނިވި ކަންކަން ކުރުމުގެ ޒިންމާ، ދަޢުވާކުރާ ފަރާތުން އުފުލަންވާނެއެވެ:
(i) އެކަށީގެންވާ މިންވަރެއްގެ ޝައްކެއްނެތް މިންވަރަށް ކުށުގެ އެންމެހައި ރުކުންތަކެއް ސާބިތުކޮށްދިނުން؛
(ii) އެކަށީގެންވާ މިންވަރެއްގެ ޝައްކެއް ނުކުރެވޭނެ މިންވަރަށް، އިސްތިސްނާގެ އެންމެހައި ޙާލަތްތަކާއި، ޢާންމު ނޫން އެންމެހައި ދިފާޢުތަކާއި، އަދި ކުށެއްކަމުގައި އެ ޢަމަލު ނުބެލުމަށް ހުރި އެންމެހައި ޙާލަތްތައް ދަޢުވާ އުފުލިފައިވާ ކުށުގެ މައްޗަށް ނުހިނގާކަން ސާބިތުކޮށްދިނުން؛ އަދި
(iii) ދަޢުވާ ރައްދުވާ ފަރާތުގެ މައްޗަށް އުފުލިފައިވާ ދަޢުވާގައި، ކުށުގެ ޒިންމާ އެފަރާތުން އުފުލަންޖެހޭކަން ސާބިތުކޮށްދިނުމަށް ބޭނުންވާ އެހެން ހުރިހާ ހެއްކަކާއި ކަންކަމެއް ލިބިހުރި އެންމެހައި ހެއްކެއްގެ ބުރަދަނަށް ބަލައި ސާބިތުކޮށްދިނުން.
