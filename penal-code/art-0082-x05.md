# Art. 82 (unnumbered item 5)
ދޫކޮށްލުން
(ޅ) މި ޤާނޫނުގެ 61 ވަނަ މާއްދާ "ކަނޑައެޅިފައިވާ މުއްދަތުގެ ތެރޭގައި ދަޢުވާ ނުއުފުލައިފިނަމަ ފަހުން ދަޢުވާ ނުކުރެވުން" ގައި ބަޔާންކޮށްފައިވާ މުއްދަތާ އެއްވަރުގެ މުއްދަތެއްގެ ތެރޭގައި ކުށެއް ކުރުމަށް ރޭވުމަށްފަހު އެ ރޭވި ރޭވުން ދޫކޮށްލިކަމުގައި ބެލެވޭނީ އެ ކުށް ކުރުމުގައި ބައިވެރިވި މީހުންގެ ތެރެއިން އެއްވެސް މީހަކު އެ ރޭވި ރޭވުމުގެ މަޤްޞަދު ޙާޞިލުކުރުމަށްޓަކައި ފާޅުވެގެންވާ އެއްވެސް ޢަމަލެއްކޮށްފިކަމުގައި ނުބެލެވޭ ނަމައެވެ.
