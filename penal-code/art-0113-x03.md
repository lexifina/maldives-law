# Art. 113 (unnumbered item 3)
އެހެން ގޮތަކަށް ސާބިތުނުވާހާހިނދަކު ޤަބޫލުކުރާނެ ގޮތް
(3) އަންނަނިވި ކަންކަން ޤަޞްދުގައި ކުރާ މީހާ، މި މާއްދާގެ (ށ) ގެ (1) ވަނަ ނަންބަރުގެ (ii) ގައި ބަޔާންކޮށްފައިވާ، އަމިއްލައަށް މަރުވާން އުޅުމުގެ ކުށްކުރަން އުޅެފިކަމުގައި، އެހެން ގޮތަކަށް ސާބިތުނުވާހާހިނދަކު، ފަނޑިޔާރު ޤަބޫލުކުރަންވާނެއެވެ.
(i) މަނާކުރެވިފައިވާ މަސްތުވާ އެއްޗެއް ނުވަތަ ބޭހުގެ ގޮތުގައި ބޭނުންކުރެވޭ މަސްތުވާއެއްޗެއް އޯވަރޑޯޒްވާ މިންވަރަށް ބޭނުންކުރުން؛
(ii) އޭނާގެ އަމިއްލަ ހަށިގަނޑަށް ޖިސްމާނީ ބޮޑެތި އަނިޔާކުރުން.
