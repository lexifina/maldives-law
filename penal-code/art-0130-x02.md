# Art. 130 (unnumbered item 2)
މާނަކުރުން
(ނ) "ރޭޕްކުރުން" ކަމަށް ބުނެފައި އެވަނީ، އެމީހެއްގެ ރުހުމަކާނުލައި، އަންހެނެއްގެ ކުރިމަތިފަރާތަށް ނުވަތަ ފުރަގަސްފަރާތަށް ފިރިހެނެއްގެ ޖިންސީ ގުނަވަން ނުވަތަ އެނޫންވެސް ގުނަވަނެއް ނުވަތަ އެއްޗެއް ކިތަންމެ ކުޑަކޮށް ނަމަވެސް ވެއްދުން ނުވަތަ ފިރިހެނެއްގެ ފުރަގަސްފަރާތަށް ފިރިހެނެއްގެ ޖިންސީ ގުނަވަން ނުވަތަ އެނޫންވެސް ގުނަވަނެއް ނުވަތަ އެއްޗެއް ކިތަންމެ ކުޑަކޮށް ނަމަވެސް ވެއްދުމަށެވެ. އެދުން ފުދުން ލާޒިމެއް ނޫނެވެ.
