# Art. 412
412. ކުށް ކަނޑައެޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) ކާވެންޏެއްގެ މަތީގައި ހުރި މީހަކު، ތިމާގެ އަނބިމީހާ ނޫން، ނުވަތަ ފިރިމީހާ ނޫން މީހަކާއެކު ހިންގި ޖިންސީ މުޢާމަލާތެއްނަމަ، އެ ކުށަކީ ޖުނަޙުގެ 1 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(2) މީހަކާ ނީނދެ ހުރި މީހަކު، ކާވެންޏެއްގެ މަތީގައިހުރި އެހެން މީހަކާ އެކު ހިންގި ޖިންސީ މުޢާމަލާތެއްނަމަ، އެ ކުށަކީ ޖުނަޙްގެ 2 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(3) މީހަކާ ނީނދެހުރި މީހަކު، މީހަކާ ނީނދެހުރި އެހެން މީހަކާއެކު ހިންގި ޖިންސީ މުޢާމަލާތެއްނަމަ، އެކުށަކީ ޖުނަޙްގެ 3 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
