# Art. 1004
1004. ކަނޑައެޅޭނެ އަދަބުގެ މިންވަރު ބަޔާންކޮށްދޭ ތާވަލުގައި ބުނާ މިންވަރުގެ އަދަބެއް، ހުއްދަ ކުރެވިފައިވާ އެހެން ގޮތެއް ބޭނުންކޮށްގެން ކަނޑައެޅިދާނެ ޙާލަތްތައް -- މި ޤާނޫނުގެ 1002 ވަނަ މާއްދާގައިވާ "ކަނޑައެޅޭނެ އަދަބުގެ މިންވަރު ބަޔާންކޮށްދޭ ތާވަލު" ގައި ކުށެއްގެ އަދަބުގައި ކުށްވެރިއަކު ޖަލަށްލެވޭނެ އެންމެ ދިގު މުއްދަތު ކަނޑައަޅާފައިވާނެއެވެ. އެހެންނަމަވެސް، އެގޮތުން ކަނޑައެޅޭނެ ޖަލުގެ މުއްދަތާ އެއް މިންވަރެއްގެ އެހެން އަދަބެއް ނުވަތަ ތަފާތު އެކިއެކި ބާވަތުގެ އަދަބުތައް އެއްކުރުމަށްފަހު ކުށްވެރިއަކު ޖަލަށްލެވޭނެ އެންމެ ދިގު މުއްދަތާ އެއްހަމަ އަދަބު އެކުށްވެރިއެއްގެ މައްޗަށް ކަނޑައެޅިދާނެއެވެ. މިގޮތުން ކަނޑައެޅޭ އަދަބުގެ މުއްދަތާއި ބާވަތް ވާންވާނީ މި ޤާނޫނުގެ 1005 ވަނަ މާއްދާގައިވާ "ތަފާތު އަދަބު އެއްހަމަ ކުރާ ތާވަލު" ގައިވާ ގޮތުގެމަތިންނެވެ.
