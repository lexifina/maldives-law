# Art. 61 (unnumbered item 3)
ދަޢުވާކުރުމަށް އޮތް މުއްދަތު ހިނގުން ހުއްޓުމަކަށް އައުން
(ނ) ކުށެއްގެ ދަޢުވާ ދައުލަތުން އުފުލުމާއެކު، އެ ކުށަކާ ގުޅިގެން، ދަޢުވާކުރުމަށް އޮތް މުއްދަތު ގުނުން ހުއްޓުމަކަށް އަންނާނެއެވެ.
(ރ) ކުށެއްގެ ދަޢުވާ ފެށިއްޖެކަމުގައި ބަލާނީ އެ ކުށުގެ ދަޢުވާގެ ޞީޣާގެ ލިޔުން ޝަރީޢަތަށް ހުށަހެޅޭ ތާރީޚުގައެވެ.
