# Art. 80 (unnumbered item 2)
ކުށެއްގެ ޢަމަލެއް ފުރިހަމަކުރުމަށްޓަކައި، އެކަށީގެންވާ ފިޔަވަޅެއް އެޅީކަމުގައި ބެލެވިދާނެ ޢަމަލު
(2) ކުށުގެ ޢަމަލު ފުރިހަމަކުރުމަށް އޮތް މަޤްޞަދު ސާފުކޮށް ދަލީލުކޮށްދޭނަމަ، އަންނަނިވި ޢަމަލުތަކަކީ، ކުށެއްގެ ޢަމަލެއް ފުރިހަމަކުރުމަށްޓަކައި، އެކަށީގެންވާ ފިޔަވަޅެއް އެޅީކަމުގައި، ޤާނޫނީ ގޮތުން ބެލިދާނެ ޢަމަލުތަކެވެ:
(i) އެ މީހެއްގެ މައްޗަށް ކުށުގެ ޢަމަލު ހިންގޭ މީހާއަށް އިންތިޒާރުކުރުމާއި، އޭނާ ހޯދުމާއި އޭނާގެ ފަހަތުން ދިޔުން؛
(ii) އެ މީހެއްގެ މައްޗަށް ކުށުގެ ޢަމަލު ހިންގޭ މީހާ، އެ ކުށް ކުރުމަށް ބޭނުންވާ ތަނަށް ގެންދިއުމަށް ލެންބުން ނުވަތަ ލެންބުމަށް މަސައްކަތްކުރުން؛
(iii) ކުށްކުރަން ބޭނުންވާ ތަން އެ ކަމަށް އެކަށީގެންވޭތޯ ބަލައި އެ ތަނުގެ މަޢުލޫމާތު ހޯދުން؛
(iv) ކުށުގެ ޢަމަލު ހިންގުމަށް ބޭނުންވާ ތަނަކީ ޢިމާރާތެއް ނުވަތަ އުޅަނދެއް ނުވަތަ އެނޫންވެސް ބަންދުކޮށްފައިވާ ތަނަކަށްވެފައި އެ ތަނަކަށް ހުއްދަނެތި ވަނުން؛
(v) ކުށުގެ ޢަމަލު ހިންގުމަށް ބޭނުންވާ ސާމާނު އަތުގައި ބެހެއްޓުމާއި، އެ ސާމާނަކީ އެ ކުށުގެ މަޤްޞަދު ޙާޞިލުކުރުމަށްޓަކައި ޚާއްޞަކޮށް ތައްޔާރުކޮށްފައިވާ އެއްޗެއްސަށްވުމާއި އެއިން އެ ޙާލަތުގައި ހުއްދަ ބޭނުމެއް ނުކުރެވޭނެ އެއްޗެއްސަށްވުން؛ ނުވަތަ
(vi) ކުށުގެ ޢަމަލު ހިންގުމަށް ބޭނުންވާ ސާމާނު އަތުގައި ބެހެއްޓުމާއި، ހޯދުމާއި، އެއާ އެއްގޮތް އެއްޗެހި ހޯދުމާއި އަދި އެއްޗެހި ކުށުގެ ޢަމަލު ހިންގުމަށް ބޭނުންވާ ތަނުގައި ނުވަތަ އެ ތަނާ ކައިރި ހިސާބެއްގައި ބެހެއްޓުމާއި، އެގޮތަށް އެ ސާމާނު ބެހެއްޓުމަކީ އެ ޙާލަތުގައި އެނޫން ހުއްދަ ބޭނުމެއް ހިފޭނެ ކަމެއްކަމަށް ނުވުން.
