# Art. 212 (unnumbered item 5)
މުދާ އަނބުރާ ހަވާލުކުރުމަށް އެންގުމުގެ ވާޖިބު
(iii) މި މާއްދާގެ މި އަކުރުގައި ބަޔާންކޮށްފައިވާ އެއްވެސް ކަމެއްގެ ސަބަބުން މީހެއްގެ މިލްކުވެރިކަމުގައިވާ މުދާ އަނބުރާ އޭނާއާ ހަވާލުކުރުމަށް އެންގުމަށް، އޭނާއަށް އޮތް ޙައްޤަކުން އޭނާ ބަރީއައެއް ނުވެއެވެ. އެފަދަ އެންގުމެއް ލިޔުމުން އަންގާ އިރުގައި، ކުލީގެ އެއްބަސްވުމުގައި ސޮއިކުރިއިރު ދަޢުވާ ރައްދުވާ މީހާ، ދީފައިވާ އެޑްރެހަށް އެފަދަ ލިޔުމެއް ޕޯސްޓުން ފޮނުވުމަކީ، ޞައްޙަ ގޮތުގައި އެންގި އެންގުމެއްކަމުގައި ބެލެވޭނެއެވެ.
