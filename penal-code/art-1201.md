# Art. 1201
1201. ޖަލަށްލުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި އަސާސީ އަދަބަކީ ޖަލަށްލުމެވެ. ނަމަވެސް އެޙާލަތްތަކުގައި ކަނޑައެޅޭ ހަމައެކަނި އަދަބަކީ ޖަލަށްލުން ކަމަށްވާކަށް ނުޖެހެއެވެ.
(1) މުޖްތަމަޢުގެ ރައްކަލަކަށްޓަކައި ކުށްވެރިޔާ މުޖްތަމަޢުން އެކަހެރިކޮށްފައި ބަންދުކުރުމުގެ ބޭނުންތެރިވުން؛
(2) ކުށްވެރިޔާ ކުރި ކުށުގެ ޢަމަލަކީ މުޖްތަމަޢު ކުށްވެރިކުރާ ނުރައްކާތެރި ޢަމަލެއްކަމަށް ދެއްކުމަށްޓަކައި ކުށްވެރިޔާ އެކަހެރިކޮށް ބަންދުކުރުން ކޮންމެހެން ބޭނުންތެރިވުން، ނުވަތަ
(3) ކުށްވެރިޔާގެ ޙާލަތަށާއި، އޭނާ ކުޅަ ކުށުގެ ޢަމަލަށް ބަލާއިރު، އެކަހެރިކޮށް ބަންދުކުރުން ފިޔަވައި އެކަށީގެންވާ އެހެން އަދަބެއް ނެތުން.
