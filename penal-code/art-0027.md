# Art. 27
27. ޢާންމުކޮށް ދެވޭ ރުހުން
(ހ) ދަޢުވާ ރައްދުވާ މީހާ ކުރި ކުށްކަމުގައި ބެލެވޭ ޢަމަލާ ގުޅޭ ގޮތުން ނުވަތަ އެ ޢަމަލުން ނުކުމެދާނެ ނަތީޖާއާ ގުޅޭގޮތުން، އެ ކުށުގެ ޢަމަލުން ގެއްލުން ލިބުނު މީހާ ދޭ ރުހުމަކީ އަންނަނިވި ޙާލަތްތަކުގައި އެ ކުށުގެ ދިފާޢެއް ކަމުގައި ބެލެވޭނެއެވެ.
(1) އެ ރުހުން ދިނުމުގެ ސަބަބުން، ކުށުގެ ރުކުންތަކުގެ ތެރެއިން ރުކުނެއް ނެތިދިއުން؛ ނުވަތަ
(2) އެ ކުށް ކަނޑައަޅާ ޤާނޫނުން މަނާކުރާ ގެއްލުންދިނުމުގެ ނުވަތަ ޢަމަލު ހިންގުމުގެ ކުރިން އެ ރުހުން ދީފައިވުން.
