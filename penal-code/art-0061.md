# Art. 61
61. މުއްދަތު ކަނޑައެޅުން
(ހ) އަންނަނިވި މުއްދަތުތަކުގައި ނުއުފުލޭ ދަޢުވާއަކީ އެ މުއްދަތު ފަހަނައަޅާ ދިޔުމުން، އުފުލިގެންވާނެ ދަޢުވާއެއް ނޫނެވެ:
(1) ޖިނާޔަތުގެ ތެރޭގައި ހިމެނޭ ކުށްކުށުގައި، އެ ކުށް ކުރި ވަގުތުން ފެށިގެން 8 އަހަރުދުވަސް؛ ނުވަތަ
(2) ޖުނަޙުގެ ތެރޭގައި ހިމެނޭ ކުށްކުށުގައި، އެ ކުށް ކުރި ވަގުތުން ފެށިގެން 3 އަހަރުދުވަސް؛
