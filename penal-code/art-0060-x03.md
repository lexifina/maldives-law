# Art. 60 (unnumbered item 3)
ދަޢުވާކުރުމަށް ހުރަހަކަށް ވެދާނެ ދިފާޢެއް އޮތް ކަމަށް ކުށްހީއެއްގައި ޤަބޫލުކުރެވުމަކީ ދިފާޢެއް ނޫނެވެ.
(ރ) މި ޤާނޫނުގައި އެހެން ގޮތަކަށް ބަޔާންކޮށްފައި ނުވާހާހިނދަކު، މީހެއްގެ ޢަމަލަކީ ދަޢުވާކުރުމަށް ހުރަހަކަށް ވެދާނެ ދިފާޢެއް ކަމުގައި ކުށްހީއަކުން އޭނާއަށް ހީވުމަކީ ދިފާޢެއް ނޫނެވެ.
