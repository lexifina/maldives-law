# Art. 30 (unnumbered item 7)
ޤާނޫނީ ގޮތުން ނުކުޅެދިގެން ވިޔަސް ޒިންމާއުފުލަންޖެހުން
(ކ) ވަކި މީހަކީ ކުށެއް ކުރުމަށް ޤާނޫނީ ގޮތުން ނުކުޅެދިގެންވާ މީހެއް ކަމުގައި ވީނަމަވެސް، އޭނާ ޤާނޫނީ ގޮތުން ޒިންމާ އުފުލަންޖެހޭ މީހެއްގެ އެހެން ސަބަބަކާހުރެ، އޭނާ ޒިންމާ އުފުލަން ނުޖެހޭ ހާލަތެއް މެދުވެރިނުވާނަމަ، އެ ކުށުގެ ޒިންމާ އޭނާ އުފުލަންޖެހޭނެއެވެ. އެއީ، އެ ޒިންމާ އުފުލުމަކީ، އޭނާގެ ނުކުޅެދުންތެރިކަން ބަޔާންކުރާ ޤާނޫނުގެ މަޤްޞަދާ ޚިލާފު ކަމަކަށް ނުވާނަމައެވެ.
