# Art. 1202 (unnumbered item 11)
ޕްރޮބޭޝަން
(އ)
(1) ޕްރޮބޭޝަންގައި ބެހެއްޓުމަށް ކަނޑައަޅާ އަދަބަކީ ކުށްވެރިޔާ އުޅޭނޫޅޭގޮތް ގާތުން ބެލުމަށް ކަނޑައަޅާ އަދަބާ ވިދިގެން ކަނޑައެޅުން ރަނގަޅު އަދަބެކެވެ. އަދި ޕްރޮބޭޝަންގައި ބެހެއްޓުމަށް، ކުށްވެރިޔާ އުޅޭނޫޅޭގޮތް ގާތުން ބެލުމުގެ މަރްޙަލާގައި ކުށްވެރިޔާގެ އުޅުން ރަނގަޅުކުރުމަށް ހިންގޭ ޕްރޮގްރާމްތަކުގައި އެކަށީގެންވާ މިންވަރަކަށް އެއްބާރުލުން ދިނުން ޝަރުޠުކުރެވިދާނެއެވެ. އިތުރު ކުށުގެ ޢަމަލު ކުރުމުން ކުށްވެރިޔާ ދުރުހެލިކުރުމަށް އޭނާގެ މިނިވަންކަމަށް ކުޑަ ހިފެހެއްޓުމެއް ގެނައުމުން ފުދޭ ޙާލަތްތަކުގައި ޕްރޮބޭޝަންގައި ބެހެއްޓުމަކީ އެކަށީގެންވާ އަދަބެކެވެ.
