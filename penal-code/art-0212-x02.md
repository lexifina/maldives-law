# Art. 212 (unnumbered item 2)
އިސްތިސްނާ
(ނ) މީހަކު މަކަރާއި ޙީލަތެއް ހެދީ އަންނަނިވި ކަންކަމާގުޅޭ ގޮތުންކަމަށްވާނަމަ އޭނާ އެކުރަނީ ކުށެއް ނޫނެވެ:
(i) މާލީ ގޮތުން އޭގެ އެއްވެސް އަހަންމިއްޔަތެއްނެތް ކަމަކާގުޅޭ ގޮތުން ކަމުގައިވުން؛ ނުވަތަ
(ii) ބުނާ އެއްޗެއްގެ ސަބަބުން ޢާންމު ވިސްނުމުގެ އަހުލުވެރިންނަށް އޮޅުމެއް ނާރާނެފަދަ އެއްޗެއް ބުނުން.
