# Art. 218
218. ކުށް ކަނޑައެޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ، އެކުރަނީ ކުށެކެވެ:
(1) އަނެކާގެ މުދާ ބަލައިގަތުމާއި ބެހެއްޓުމާއި އޭގެ ތަޞައްރުފެއް ކުރުން.
(2) އެ މުދަލަކީ ވައްކަންކޮށްފައިވާ މުދާކަން ކަށަވަރުކުރުމުގައި ފަރުވާ ބަހައްޓައިފައިނުވުން.
(3) އެ މުދާ އޭނާ ބަލައިގަތީ ނުވަތަ ބެހެއްޓީ އެ މުދަލުގެ ވެރިފަރާތަށް ރައްދުކުރުމަށްކަމަށް ނުވުން.
