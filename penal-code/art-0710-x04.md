# Art. 710 (unnumbered item 4)
އަދަބު ކަނޑައެޅުމުގައި ބަލަންޖެހޭ ނުކުތާ
(ބ) އިރު އޮއްސުމާއިއިރު އެރުމާ ދެމެދު ހިނގާ ވަގުތުގައި ކުށުގެ އެ ޢަމަލު ހިންގައިފިނަމަ މި ޤާނޫނުގެ 1002 ވަނަ މާއްދާގައި އަދަބު ކަނޑައެޅުމުގެ މިންގަނޑު އަންގައިދޭ ތާވަލުގައި ބަޔާންކޮށްފައިވާ އަސާސީ އަދަބުގެ މިންގަނޑުން އެއް ދަރަޖަ އެ ކުށުގެ އަދަބަށް އިތުރުކުރެވިގެންވެއެވެ.
