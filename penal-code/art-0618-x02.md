# Art. 618 (unnumbered item 2)
މަދަނީ ބަދަލު ދިނުމުން އިމްތިޔާޒު ލިބިގެންވުން
(ނ) މި މާއްދާގެ ދަށުން އެހީތެރިކަން ފޯރުކޮށްދޭ މީހާ ނުވަތަ އިންޒާރުދޭ މީހާކުރާ ޢަމަލެއްގެ ސަބަބުން ލިބޭ ގެއްލުމަށް ބަދަލު ދިނުމުން އޭނާއަށް އިމްތިޔާޒު ލިބިގެންވާނެއެވެ. އެއީ އޭނާ އެކުރާ ޢަމަލުކުރީ ހެޔޮނިޔަތުގައިކަމަށްވުމާއި، އެކަންކުރުމަށް އޮތް އެކަށޭނަ މިންގަނޑުތަކުގެ ތެރޭގައި ކަމަށްވުމާއި، އަދި އެހީތެރިކަން ފޯރުކޮށްދިނުމާއި އަޅާލުމުގެ ވާޖިބު އަދާކުރުމަށް އޮންނަ މިންގަނޑުތަކުގެ ތެރޭގައިކަމަށްވާނަމައެވެ.
