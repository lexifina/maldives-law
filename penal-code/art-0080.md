# Art. 80
80. ކުށެއް ކުރަން އުޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި މީހަކު ކުރާ ޢަމަލަކީ ކުށެއް ކުރަން އުޅުމުގެ ޢަމަލެކެވެ:
(1) ކުށެއް ކުރުމަށްޓަކައި ކުށުގެ ނިޔަތް އޮތުން؛
(2) ކުށުގެ ޢަމަލު ފުރިހަމަކުރުމަށްޓަކައި އެކަށީގެންވާ ފިޔަވަޅެއް އަޅައިފިކަން ރަމްޒުކޮށްދޭފަދަ ޢަމަލެއް ޤަޞްދުގައި ކުރުން؛ އަދި އެ ޢަމަލު ކުރީ ކުށްކުރުމަށް ބޭނުންވާ ޙާލަތު ދެމިއޮތްކަމުގައި ޤަބޫލުކޮށްގެން ކަމުގައިވުން.
