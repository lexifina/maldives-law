# Art. 82 (unnumbered item 3)
ކުށެއްކުރުމަށް ރޭވި ރޭވުމެއްގެ މުއްދަތު
(ރ) ކުށެއް ކުރުމަށް ރޭވި ރޭވުމުގެ މަޤްޞަދު ޙާޞިލުވުމާ ހަމައަށް ނުވަތަ އެ ރޭވުމާ އެއްގޮތަށް ޢަމަލުކުރެވެން ނެތުމާ ހަމައަށް ނުވަތަ އެ ރޭވި ރޭވުން ދޫކޮށްލުމާ ހަމައަށް އެ ރޭވުން ދެމިއޮތްކަމުގައި ބެލެވޭނެއެވެ. މި މާއްދާގެ (ހ) ގެ ދަށުން ކުށެއް ކުރާ މީހާ ބެލެވޭނީ، އެ މުއްދަތުގެ ތެރޭގައި އެ ކުށް ރޭވި މީހުންގެ ތެރޭގައި ހިމެނޭ މީހެއްކަމަށެވެ. އަދި އެއީ އޭނާ އެ ކަމުން އަމިއްލައަށް ތަނާޒުލު ނުވާހާހިނދަކުއެވެ.
