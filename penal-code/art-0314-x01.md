# Art. 314 (unnumbered item 1)
ރިޝްވަތެއް ހުށަހެޅުމާއި މަންފާއެއްގެ ގޮތުގައި ފައިސާ ދިނުން
(ށ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލު ކުރާ މީހާ، އެކުރަނީ ކުށެކެވެ:
(1) އެނގިހުރެ މީހަކަށް މަންފާއެއް ހޯދައިދިނުން، ނުވަތަ މަންފާއެއް ދިނުމަށް ހުށަހެޅުން ނުވަތަ މަންފާއެއްގެ ގޮތުގައި ފައިސާ ދިނުން. އަދި
(2) އެއްޗަކީ މި މާއްދާގެ (ހ) ގެ ދަށުން ޤަބޫލުކުރުމުގެ ހުއްދަނެތް އެއްޗެއް ކަމުގައިވުން.
