# Art. 80 (unnumbered item 1)
އެކަށީގެންވާ ފިޔަވަޅެއް އަޅައިފިކަން ރަމްޒުކޮށްދޭ ޢަމަލު
(ށ)
(1) ކުށުގެ ޢަމަލެއް ފުރިހަމަކުރުމަށްޓަކައި އެކަށީގެންވާ ފިޔަވަޅެއް މި މާއްދާގެ (ހ) ގެ (2) ވަނަ ނަންބަރުގައިވާ ފަދައިން މީހަކު އަޅައިފިކަމުގައި ބެލެވޭނީ އެ ކުށުގެ ޢަމަލު ފުރިހަމަކުރުމަށް އޮތް އޭނާގެ މަޤްޞަދު އެޢަމަލުން ސާފުކޮށް ދަލީލުކޮށްދޭ ނަމައެވެ.
