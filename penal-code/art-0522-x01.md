# Art. 522 (unnumbered item 1)
ހިނގާފައިނުވާ ކަމެއްގެ ރިޕޯޓު ދިނުން
(ށ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލު ކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) ހިނގާފައިނުވާ ކުށެއް ނުވަތަ ކަމެއް ހިނގައިފިކަމުގެ މަޢުލޫމާތު، ޤާނޫނު ތަންފީޒުކުރާ އިދާރާއަކަށް ދިނުން؛ ނުވަތަ
(2) ހިނގާފައިވާ ކުށެއް ނުވަތަ ހިނގާފައިވާ ކަމަކާ ގުޅޭ ގޮތުން މަޢުލޫމާތެއް ލިބިފައިނެތް މީހަކު، އެފަދަ މަޢުލޫމާތެއް އޭނާއަށް ލިބިގެންވާކަމުގައި ޤާނޫނު ތަންފީޒުކުރުމުގެ އިދާރާއަކަށް ދެއްކުމާއި، އެގޮތުން އެއްވެސް މަޢުލޫމާތެއް ދިނުން.
