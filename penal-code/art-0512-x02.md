# Art. 512 (unnumbered item 2)
އަދަބު ކަނޑައެޅުމުގައި ބަލާ ނުކުތާ
(ނ) މި ޤާނޫނުގެ 1002 ވަނަ މާއްދާގައިވާ އަދަބު ކަނޑައެޅުމުގެ މިންގަނޑުތަކުގެ ތާވަލުގައި ބަޔާންކޮށްފައިވާ ޙުކުމް ކަނޑައެޅުމުގެ މިންގަނޑުގެ އެންމެ އަސާސީ މިންގަނޑުގައި ހިމެނޭ އަދަބު، މި މާއްދާގައި ބަޔާންކުރާ ކޮންމެ ކުށަކަށް އެއް ދަރަޖަ މައްޗަށް އުފުލިގެންވެއެވެ. އެއީ، ދައުލަތުގެ މުވައްޒަފަކު، އެ ކުށްކޮށްފައިވަނީ ތިމާއަށް ނުވަތަ ތިމާގެމީހަކަށް ނުވަތަ ރަޙްމަތްތެރިއަކަށް މަންފާއެއް ހޯދައިދިނުމުގެ މުޤާބިލުގައިކަމަށް ވާ ނަމައެވެ.
