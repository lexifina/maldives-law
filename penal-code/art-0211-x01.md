# Art. 211 (unnumbered item 1)
މާނަކުރުން
(ށ) "އަނެކާގެ މުދާ" ކަމަށް ބުނެފައި އެވަނީ، ކުށުގެ ޢަމަލު ހިންގި މީހާއަށް ވުރެ، އެ މުދާ އެ ވަގުތު އެ މީހެއްގެ އަތުގައި ހުރި މީހާއަށް، އެ މުދަލާ ގުޅޭ ގޮތުން، ވަގުތީ، ނުވަތަ ދާއިމީ، ނުވަތަ ޣައިރުޤާނޫނީ ނަމަވެސް މަތީ ނުވަތަ ބޮޑު ޙައްޤެއް އެ ވަގުތު ލިބިފައިވާ މުދަލަށެވެ. ސަރުކާރު، ނުވަތަ ކުންފުނި ފަދަ ޤާނޫނީ ޝަޚްޞަކަށްވެސް މުދަލަކާ ގުޅިގެން އެފަދަ ޙައްޤެއް އޮވެދާނެއެވެ.
