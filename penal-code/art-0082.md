# Art. 82
82. ކުށް ކަނޑައެޅުން
(ހ) މީހަކާ އެކު ނުވަތަ އެއަށް ވުރެ ގިނަ ބަޔަކާ އެކު އަންނަނިވި ޢަމަލުތައް ކުރާ މީހާ، ކުށެއްކުރުމަށް ރޭވީ ކަމުގައި ބެލެވޭނެއެވެ:
(1) އެ ޢަމަލު އެކުރަނީ:
(i) ކުށެއް ކުރުމުގެ ނިޔަތް އޮވެގެން ކަމުގައިވުން؛ އަދި
(ii) އެ މަޤްޞަދު ޙާޞިލު ކުރުމަށްޓަކައި ނުވަތަ އެކަން ފަސޭހަކުރުމަށްޓަކައި ކަމުގައިވުން.
(2) ކުށުގެ ޢަމަލުގެ ގޮތުގައި ބެލެވޭ ޢަމަލު ހިންގުމުގައި ބައިވެރިވުމަށް އެހެން މީހަކާ އެކު ނުވަތަ ބަޔަކާ އެކު އެއްބަސްވުން.
(3) އެ މީހުންގެ ތެރެއިން ކޮންމެވެސް އެކަކު އެރޭވި ރޭވުމުގެ މަޤްޞަދު ޙާޞިލުކުރުމަށްޓަކައި ކުރަންޖެހޭ ޢަމަލެއް ކުރުން.
