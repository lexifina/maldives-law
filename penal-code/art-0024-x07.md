# Art. 24 (unnumbered item 7)
ކުށުގެ ނިޔަތުގެ ދަރަޖައެއް ބަޔާންކޮށްފައި ނުވާނަމަ ބަލާނެ މިންގަނޑު
(އ) ކުށުގެ މަޤްޞަދުގެ ރުކުނަކާ ގުޅޭގޮތުން ސާބިތުކުރުމަށް ބޭނުންވާ ކުށުގެ ނިޔަތުގެ މިންގަނޑު، އެ ކުށް ކަނޑައެޅުމުގައި ބަޔާންކޮށްދީފައިނުވާނަމަ، ނުވަތަ އެ ކުށުގެ ދަރަޖަ ކަނޑައަޅާ މާއްދާގައި ބަޔާންކޮށްދީފައިނުވާނަމަ، އެ ރުކުނަކާ ގުޅޭ ގޮތުން ކުށުގެ ނިޔަތް ސާބިތުކޮށްދިނުމަށް ބޭނުންވާނެ އެންމެ ކުޑަ މިންވަރަކީ، އެ ކުށް ކުރި މީހާ ފަރުވާކުޑަކުރިކަން ސާބިތުކޮށްދިނުމެވެ.
