# Art. 215
215. ކުށް ކަނޑައެޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) އެއްބަސްވުމެއްގެ ދަށުން ނުވަތަ ޤާނޫނީ އިލްތިޒާމެއްގެ ދަށުން ނުވަތަ ޒިންމާއުފުލަންޖެހޭ މަޞްލަޙަތެއް އޮންނަ ޙާލަތުގައި، އަނެކާގެ މުދަލެއް މީހަކު ލިބިގަންނަނީ، އަގެއް އަދާކުރުމަށް ނުވަތަ އެ މުދަލުން ވަކި ތަޞައްރުފެއް ކުރުމަށްކަމުގައި ވެފައި؛
(2) އޭނާގެ އަމިއްލަ މުދަލުގެ ގޮތުގައި އެ މުދަލުން މުޢާމަލާތްކޮށް؛
(3) އެ މުދަލަކުން އަދާކުރަން ޖެހޭ އަގު އަދާނުކުރުން ނުވަތަ އެއިން ކުރަންޖެހޭ ތަޞައްރުފު ނުކުރުން.
