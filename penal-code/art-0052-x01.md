# Art. 52 (unnumbered item 1)
އިޖްތިމާޢީ މިންގަނޑުތަކާ ދެކޮޅު ޝަޚްޞުތައް އެކަހެރި ކުރެވިގެންވުން
(ށ) މި މާއްދާގެ (ހ) ގެ ބޭނުމަށްޓަކައި، ސިކުނޑިއަށް ޖެހިފައިވާ ބައްޔެއް ނުވަތަ ނުކުޅެދުމެއްކަމުގައި ބެލެވޭ ކަންކަމުގެ ތެރޭގައި، ހަމައެކަނި ތަކުރާރުކޮށް ކުށްކުރާ ކުށްވެރިންނާއި، ޢާންމު އިޖްތިމާޢީ މިންގަނޑުތަކާ ދެކޮޅު ޢަމަލުތައް ހިންގާ މީހުންކަމުގައި ބެލެވޭ މީހުންގެ ކިބައިން އެކަނި ހާމަވާ ސިކުނޑީގެ ޙާލަތްތަކެއް ހިމެނިގެނެއްނުވެއެވެ.
