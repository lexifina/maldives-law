# Art. 240 (unnumbered item 1)
އިސްތިސްނާ
(ނ) ކޯޓު އަމުރެއްގެ ދަށުން، ނުވަތަ ޤާނޫނަކުން ބާރު ލިބިގެން ދޫކޮށްފައިވާ ހުއްދައެއްގެ ދަށުން، އެ ކޯޓު އަމުރުގައި ނުވަތަ ހުއްދައިގައި ބަޔާންކުރާ ގޮތުގެމަތިން ކޮމްޕިއުޓަރަކަށް ނުވަތަ ޕްރޮގްރާމަކަށް ނުވަތަ ޑޭޓާއަކަށް ނުވަތަ އެއިން އެއްޗެއްގެ ވަކި ބަޔަކަށް އެކްސެސްވުމަކީ ކުށެއް ކަމުގައެއް ނުބެލެވޭނެއެވެ.
