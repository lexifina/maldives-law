# Art. 314 (unnumbered item 2)
ތިމާގެ މަޞްލަޙަތެއް ނެތް ގޮތުގައި މަސައްކަތްކުރުމުގެ ވާޖިބާ ޚިލާފުވުން
(ނ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ، އެކުރަނީ ކުށެކެވެ:
(1) ވަކި ކަމެއްގައި އެއްވެސް ފަރާތަކަށް ނުޖެހި ނިންމުންތައް ނިންމުމާއި، އަގުކުރުމާއި، މުދަލާ ޚިދުމަތަށް ފާޑުކިޔާ މީހެއްގެ ގޮތުގައި ހުރެ؛ އަދި
(2) އެނިންމުމަށް ނުވަތަ އަގުކުރުމަށް ނުވަތަ ފާޑުކިޔުމަށް ނުފޫޒު ފޯރުވުމަށްޓަކައި ދެވޭ މަންފާއެއްކަން އެނގިހުރެ، އެފަދަ މަންފާއެއް ހޯދުމާއި ޤަބޫލުކުރުން.
