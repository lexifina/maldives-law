# Art. 55
55. ބާރުގެ ބޭނުންކޮށްފާނެކަމުގެ ނުފޫޒު
(ހ) ކުށްކުރި ވަގުތު އެ ކުށް ކުރީ އަންނަނިވި ޙާލަތްތަކުގައިކަމުގައި ވާނަމަ، އެ ކުށްކުރި މީހާ ކުރި ކުށަށް އޭނާ އަށް މަޢާފުލިބިގެންވެއެވެ:
(1) ކުށުގެ ޢަމަލު ކުރުމަށް އޭނާއަށް މަޖުބޫރުކުރެވިގެންވުން؛
(2) އެގޮތުން މަޖުބޫރުކުރުވީ، ކުށުގެ ޢަމަލު ކުރުމަށް ދެކޮޅުހަދައިފިނަމަ، އޭނާއަށް ގެއްލުމެއް ކުރިމަތިވެދާނޭކަމުގެ ބިރު ދައްކުވައިގެންކަމުގައި ވުމާއި، އެކަށީގެންވާ ހަރުދަނާކަމާއެކު ވިސްނާ އެހެން މީހަކަށް އެ ޙާލަތުގައި، އެ ގެއްލުމުގެ ބިރު ކުރިމަތިވީނަމަ، އޭނާވެސް އެ ކުށުގެ ޢަމަލު ކުރާނެ ކަމުގައިވުން.
