# Art. 23
23. ޒިންމާ އުފުލުމުގެ މިންގަނޑުތައް
(ހ) ކުށުގެ ޒިންމާ އުފުލުން، ޢަމަލެއްގެ މައްޗަށް އެކަނިވެސް ބުރަވެފައި އޮވެދާނެއެވެ. އެގޮތުން، އެ ޢަމަލުގެ މާނައިގައި، ކުރާ ކަންކަން، ނުވަތަ ޤާނޫނު ހުއްދަނުކުރާ ގޮތެއްގެ މަތިން އަތުގައި އެއްޗެއް ބެހެއްޓުން، ނުވަތަ އުފުލަންޖެހޭކަމަށް ޤާނޫނުގައި ބަޔާންކުރާ ޒިންމާއެއް ނުއުފުލައި ދޫކޮށްލުން ހިމެނެއެވެ.
