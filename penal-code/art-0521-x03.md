# Art. 521 (unnumbered item 3)
މާނަކުރުން
(ރ) "ޤާނޫނު ތަންފީޒުކުރާ މުވައްޒަފު" ކަމަށް ބުނެފައި އެވަނީ، އޭނާގެ މަޤާމުގެ ހައިސިއްޔަތުން ނުވަތަ އަދާކުރާ ރަސްމީ ވަޒީފާގެ ހައިސިއްޔަތުން އަމަން އަމާންކަން ދެމެހެއްޓުން، ނުވަތަ ކުށްކުރާ މީހުން ހައްޔަރު ކުރުން ނުވަތަ ޖިނާއީ ކުށުގެ މައްސަލަތައް ތަޙްޤީޤު ކުރުމުގެ ވާޖިބު، ޤާނޫނެއްގެ ދަށުން އަދާކުރަން ޖެހޭ ކޮންމެ މީހެކެވެ.
