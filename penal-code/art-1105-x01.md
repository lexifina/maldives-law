# Art. 1105 (unnumbered item 1)
ބަދަލުދިނުން
(ށ) މި މާއްދާގެ (ހ) ގެ ދަށުން ދޭ ބަދަލު ދިނުމަކީ ކުށްވެރިޔާގެ މާލީ އަދި އެހެނިހެން ފޯރުންތެރިކަން ހުރި މިންވަރަކުން ކުށްވެރިޔާގެ ޢަމަލުގެ ސަބަބުން ލިބުނު ގެއްލުމުގެ ބަދަލު ލިބިގަތުމަށާއި، ގެއްލުން ލިބުނު ފަރާތް މަޙްރޫމްވެފައިވާ އެކިއެކި ފައިދާތަކާއި މަންފާތަކަށް އެކަށީގެންވާ ބަދަލު ދިނުމެވެ. މިގޮތުން ކުށްވެރިޔާ ލިބިދޭންޖެހޭ ބަދަލު އެންމެ ފުރިހަމަ ގޮތުގައި އެހިނދުން އެހިނދަށް ދިނުމުގެ ޤާބިލިއްޔަތުކަން އޭނާއަށް ލިބިފައި ނުވިނަމަވެސް، އޭނާގެ ޤާބިލިއްޔަތު ތަންދިން އެންމެ މަތީ ދަރަޖައަކަށް، ގެއްލުން ލިބުނު މީހާއަށް ލިބުނު ގެއްލުމުގެ ބަދަލު މުސްތަޤްބަލުގައި ވިޔަސް ދޭންވާނެއެވެ.
