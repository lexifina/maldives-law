# Art. 616 (unnumbered item 1)
ދަރަޖަކުރުން
(ށ)
(1) މިކުށަކީ ޖުނަޙްގެ 3 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(2) މި ޤާނޫނުގެ 90 ވަނަ ބާބުގެ ދަށުން ހުއްދަކޮށްފައިވާ އަދަބުގެ އިތުރަށް 40 އެތިފަހަރުން ޖަލްދުކުރުމުގެ އަދަބު މި ޤާނޫނުގެ 411 ވަނަ މާއްދާގެ (ޅ) ގެ (3) ވަނަ ނަންބަރުގައި ހުއްދަކޮށްފައިވާ ގޮތުގެމަތިން، މި މާއްދާގެ (ހ) ގެ (2) ވަނަ ނަންބަރުގެ (ii) ގައިވާ ކުށަށް، ހުއްދަކުރެވިގެންވެއެވެ.
