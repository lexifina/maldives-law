# Art. 1203
1203. ޝަރުޠުތަކާ އެއްގޮތަށް ޢަމަލުނުކުރުމުގެ ނަތީޖާ
(ހ) ޖަލަށްލުން ފިޔަވާ ކަނޑައެޅޭ އެހެނިހެން އަދަބުތަކުގެ ޝަރުޠުތަކާ އެއްގޮތަށް ކުށްވެރިޔާ ޢަމަލުނުކޮށްފިނަމަ، ކުށްވެރިޔާގެ މައްޗަށް ޖަލަށްލުން ފިޔަވާ ކަނޑައެޅޭ އެހެނިހެން އަދަބު ކަނޑަނޭޅިނަމަ އޭނާގެ މައްޗަށް ކަނޑައަޅަންޖެހޭ ޖަލަށްލުމުގެ އަދަބު، ވަގުތުން ތަންފީޒުކުރުމަށް ކޯޓުން އެންގިދާނެވެ.
