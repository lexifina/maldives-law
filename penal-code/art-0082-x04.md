# Art. 82 (unnumbered item 4)
ތަނާޒުލުވުން
(ބ) ކުށެއް ކުރުމަށް ރޭވުމަށްފަހު މީހަކު އެ ކަމުން ތަނާޒުލުވެއްޖެ ކަމުގައި ބެލެވޭނީ އަންނަނިވި ކަންކަން އެ މީހަކު ކޮށްފިކަމުގައިވާނަމައެވެ:
(1) އެ ރޭވުމުގައި އޭނާއާއެކު ބައިވެރިވި މީހުންނަށް އެ ރޭވުން އޭނާ ދޫކޮށްލައިފިކަން އެންގުން؛ ނުވަތަ
(2) އެފަދަ ރޭވުމެއް އޮތްކަން ޤާނޫނު ތަންފީޒުކުރުމުގެ އިދާރާތަކަށް އެންގުމާއި އެކަމުގައި އޭނާ ބައިވެރިވިކަންވެސް އެންގުން.
