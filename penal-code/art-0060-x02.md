# Art. 60 (unnumbered item 2)
ދަޢުވާކުރުމަށް ހުރަހަކަށް ވެދާނެ ދިފާޢު ހިއްސާނުކުރެވުން
(ނ) ދަޢުވާކުރުމުގައި ހުރަހަކަށް ވެދާނެ ދިފާޢެއްގެ ފައިދާ ލިބުން ޙައްޤުވާ މީހާ ކުށުގެ ޢަމަލު ހިންގާއިރު އޭނާއަށް ހަމައެކަނި އެހީތެރިވެދިން ކަމަށްޓަކައި، އެގޮތުން އެހީތެރިވެދިން މީހާއަކަށް އެ ދިފާޢުގެ ފައިދާއެއް ނުލިބޭނެއެވެ.
