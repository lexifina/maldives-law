# Art. 510 (unnumbered item 1)
ރިޝްވަތުދިނުމަށް ހުށަހެޅުން
(ށ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލު ކުރާ މީހާ، އެކުރަނީ ކުށެކެވެ:
(1) އެނގިހުރެ ދައުލަތުގެ މުވައްޒަފަކަށް މަންފާއެއް ދިނުން ނުވަތަ ދިނުމަށް ހުށަހެޅުން.
(2) އެ މަންފާއަކީ، ޤާނޫނުގައި ހުއްދަކޮށްފައިނުވާ އަދި އަންނަނިވި ކަންކަމުގެ މުޤާބިލުގައިއޮތް އެއްޗަކަށްވުން:
(i) ރަސްމީ ހައިސިއްޔަތުން އަދާކުރަން ޖެހިފައިވާ ވާޖިބަށް ނުފޫޒު ފޯރުވުމުގެ ގޮތުން ނުވަތަ ނުފޫޒު ފޯރުވުމަށް އެއްބަސްވުމުގެ ގޮތުން؛
(ii) ތިމާ ރަސްމީ ހައިސިއްޔަތުން ކުރަންޖެހޭ ކަމެއް ކުރުމުގެ ގޮތުން ނުވަތަ ނުކޮށް ދޫކޮށްލުމުގެ ގޮތުން.
