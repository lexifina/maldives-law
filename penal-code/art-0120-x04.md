# Art. 120 (unnumbered item 4)
އަދަބު ކަނޑައެޅުމުގައި ވިސްނަން ޖެހޭ ނުކުތާ
(ނ) އަނިޔާކުރީ މީހަކު އޭނާ ދިރިއުޅޭ ގޭގައި ހުއްޓާ ކަމުގައިވާނަމަ ނުވަތަ ގެއެއްގައި މެހުމާނެއްގެ ގޮތުގައި ހުއްޓާ ކަމަށްވާނަމަ، މި މާއްދާގެ ދަށުން ކުށެއްކަމަށް ބަލާ ކޮންމެ ޢަމަލަކަށް ދެވޭ އަދަބު، މި ޤާނޫނުގެ 1002 ވަނަ މާއްދާގައިވާ އަދަބު ކަނޑައެޅުމުގައި ބަލާނެ މިންގަނޑުތަކުގެ އެންމެ އަސާސީ މިންގަނޑުގެ މައްޗަށް އެއް ދަރަޖަ އުފުލިގެން ވާނެއެވެ.
