# Art. 1204 (unnumbered item 1)
އިޢްތިރާފް
(ށ) އަދަބެއްގެ ގޮތުގައި މީހެއްގެ މައްޗަށް މަރުގެ ޙުކުމް އައިސްފާނެފަދަ ކުށަކަށްވާ އިޢްތިރާފަކީ، ހުޅުވާލެވިގެންވާ ކޯޓެއްގައި އަދި ވަކީލެއްގެ އެހީތެރިކަން ލިބިހުރެ އެމީހަކު އެކުށުގެ އެންމެހާ ރުކުންތަކަށް އަމިއްލަ އިޚްތިޔާރުގައިވެފައިވާ އިޢްތިރާފަކަށް ނުވާހާހިނދަކު، އެމީހެއްގެ މައްޗަށް މަރުގެ އަދަބު ދިނުމުގެ ބޭނުމުގައި، އެފަދަ ކުށެއް ސާބިތުކުރުމަށް ހަމައެކަނި އޭނާވެފައިވާ އިޢްތިރާފް ހެއްކެއްގެ ގޮތުގައި ދައުލަތުން ބޭނުންކޮށްގެން ނުވާނެއެވެ.
