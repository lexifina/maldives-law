# Art. 53
53. ތަޞައްރުފުނުފުދުމުން މަޢާފުލިބިގެންވުން
(ހ) ކުށްކުރި މީހާއަކީ، ކުށްކުރި ހިނދުގައި އަންނަނިވި ޙާލަތްތަކުގެ ތެރެއިން ޙާލަތެއްގައި ހުރި މީހެއްކަމުގައި ވާނަމަ، އޭނާގެ ކުށަކީ މަޢާފުލިބިގެންވާ ކުށެކެވެ:
(1) ބޮޑުމީހަކަށް ލިބިގެންވާ ތަޞައްރުފުފުދުމުގެ ޤާބިލުކަން ލިބިފައިވާ މީހަކަށް ނުވުމާއި، އަދި
(2) އެ ޤާބިލުކަން ނެތުމުގެ ނަތީޖާއެއްގެ ގޮތުން އަންނަނިވި ކަންކަން ކުރުމަށް އޭނާ ނުކުޅެދިގެންވުން:
(i) ކުށުގެ ޢަމަލުގެ ގޮތުގައި ބެލެވޭ ޢަމަލުގެ ބާވަތާއި ނަތީޖާ އެކަށީގެންވާ ގޮތުގައި ވިސްނައިގަތުމަށް ނުކުޅެދިގެންވުން؛ ނުވަތަ
(ii) ކުށުގެ ޢަމަލުގެ ގޮތުގައި ބެލެވޭ ޢަމަލުގެ ނުރަނގަޅުކަން ވިސްނައިގަތުމަށް ނުކުޅެދިގެންވުން؛ ނުވަތަ
(iii) ކުށުގެ ޢަމަލުގެ ގޮތުގައި އޭނާ ހިންގި ޢަމަލު ހުއްޓުމަށްޓަކައި، ބާރެއް ހިންގުމަށް ނުކުޅެދިގެންވުން.
