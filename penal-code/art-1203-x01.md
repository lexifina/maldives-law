# Art. 1203 (unnumbered item 1)
ޖަލަށްލުން ފިޔަވާ ކަނޑައެޅޭ އެހެނިހެން އަދަބުގެ ޝަރުޠުތަކާ އެއްގޮތަށް ޢަމަލުނުކުރިކަން ކަނޑައެޅުން
(ށ) ކުށްވެރިޔާގެ މައްޗަށް ކަނޑައެޅިފައިވާ ޖަލަށްލުން ފިޔަވާ ކަނޑައެޅޭ އެހެނިހެން އަދަބުގެ ޝަރުޠުތަކާ އެއްގޮތަށް ޢަމަލުކޮށްފައިނުވާކަން ސާބިތުކުރުމަށް، ދައުލަތުގެ ފަރާތުން ޝަރީޢަތުގެ މަޖިލީހަށް ސާފު ހެކި ހުށަހަޅައިފިނަމަ، އެޝަރުޠުތަކާ އެއްގޮތަށް ޢަމަލުކުރިކަން ސާބިތުކޮށްދިނުމަކީ ކުށްވެރިޔާގެ ޒިންމާއެކެވެ. މިގޮތުން ބަންދު ފިޔަވާ ކަނޑައެޅޭ އެހެނިހެން އަދަބުގެ ޝަރުޠުތަކާ އެއްގޮތަށް ޢަމަލުކުރިކަން ކުށްވެރިޔާއަށް ސާބިތުކޮށް ނުދެވިއްޖެނަމަ، މި މާއްދާގެ (ހ) ގައިވާ ގޮތުގެމަތިން ކުށްވެރިޔާގެ މައްޗަށް އަލުން އަދަބު ކަނޑައެޅުމުގެ އިޚްތިޔާރު ކޯޓަށް ލިބިގެންވެއެވެ.
