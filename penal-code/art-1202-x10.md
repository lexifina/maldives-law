# Art. 1202 (unnumbered item 10)
މުއްދަތު
(2) ފަރުވާގެ ޕްރޮގްރާމެއްގައި ބައިވެރިކުރުމަށް އަމުރު ކުރަންވާނީ ފަރުވާގެ ޕްރޮގްރާމްގެ މުއްދަތަކީ އެޕްރޮގްރާމްގެ މަޤްޞަދު ޙާޞިލުވުމަށް އެކަށީގެންވާ މުއްދަތަކަށްވާނަމައެވެ. ފަރުވާގެ ޕްރޮގްރާމަށް ބޭނުންވާނެ މުއްދަތާބެހޭގޮތުން އެކަމާބެހޭ މާހިރުންނާ ކޯޓުން މަޝްވަރާކުރަންވާނެއެވެ. ފަރުވާގެ ޕްރޮގްރާމްގައި ކުށްވެރިއަކު ޢާންމުކޮށް ބައިވެރިކުރަންވާނީ، ޖަލަށްލުމުގެ އަދަބުގެ މުއްދަތުގައި ނުވަތަ ޖަލަށްލުމުގެ އަދަބުގެ ފަހުންނެވެ. ޖަލަށްލުމުގެ އަދަބުގެ ކުރިއަކުންނެއްނޫނެވެ. ޚާއްޞަކޮށް ފަރުވާގެ ޕްރޮގްރާމަކަށްފަހު އެ ޕްރޮގްރާމްގެ ސަބަބުން ކުށްވެރިޔާއަށް ކޮށްފައިވާ އެދެވޭ އަސަރު ދެނެގަތުމަށްޓަކައި ޓެސްޓު ކުރަން ޖެހޭ ޙާލަތްތަކުގައާއި، ފަރުވާގެ ޕްރޮގްރާމާ ވިދިގެން ގޭގައި ބަންދުކުރުމާއި ކުށްވެރިޔާ އުޅޭނޫޅޭގޮތް ގާތުން ބެލުމަށް ދޫކޮށްފައި ބެހެއްޓުމަށް ޙުކުމް ކުރެވިދާނެއެވެ.
