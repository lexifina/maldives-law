# Art. 1204
1204. ސާބިތުވާންޖެހޭ މިންވަރު
(ހ) މީހެއްގެ މައްޗަށް މަރުގެ ޙުކުމް ކުރުމަށްޓަކައި، ދައުލަތުން ކުށުގެ އެންމެހައި ރުކުންތައް ސާބިތުކޮށްދޭންވާނެއެވެ. އަދި އެމީހަކު އެކުރި ކުށަކީ އެހެން އެއްވެސް ކުށަކަށް ވުރެ ބޮޑު ކުށެއް ކަމާއި، އަދި އެ ކުށް ކުރުމުގެ ނިޔަތް އެމީހެއްގެ އޮތްކަން ޢަމަލީގޮތުން ޔަޤީންކުރެވޭ މިންވަރަށް ދައުލަތުން ސާބިތުކޮށްދޭންވާނެއެވެ.
