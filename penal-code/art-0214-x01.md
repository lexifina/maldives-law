# Art. 214 (unnumbered item 1)
މާނަކުރުން
(ށ) "ޚިދުމަތް" ކަމަށް ބުނެފައި އެވަނީ، މީހުން ލައްވާ ކުރުވާ މަސައްކަތަށާއި، ފަންނީ ޚިދުމަތަށާއި، މުއާޞަލާތުގެ ވަސީލަތްތަކަށާއި، ޢާންމު ބޭނުންތަކުގެ ޚިދުމަތްތަކަށާއި، ގޭގޭގައި ނުވަތަ ހޮޓާހޮޓަލުގައި މީހުން ބޭތިއްބުމުގެ ޚިދުމަތަށާއި، މަޢްރަޟުތަކަށް މީހުން ވެއްދުމަށާއި، ފިކުރީ ނުވަތަ އުފުލޭ މުދާ ބޭނުންކުރުމަށާއި، އިލެކްޓްރޯނިކް ޚިދުމަތެއްގެ ބޭނުންހިފުން ހިމެނޭ ގޮތުންނެވެ. އެކަމަކު އެކަންކަމަށް އެކަނިމެ މަޙްދޫދު ނުވާނޭ ގޮތުގެމަތިންނެވެ.
