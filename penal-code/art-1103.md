# Art. 1103
1103. ފަރުވާލެއްނެތް އަނިޔާވެރިކަމެއް ދެއްކުމުން އަދަބުގެ މިންވަރު މަތިވުން -- ކުށްވެރިޔާ، ކުށުގެ ޢަމަލު ހިންގީ ފަރުވާލެއްނެތް އަނިޔާވެރިކަމެއް ދެއްކުމާއެކުނަމަ ނުވަތަ އިންސާނެއްގެ ޤަދަރާއި ކަރާމާތަށް ކަނޑައެޅިގެން ފަރުވާތެރިކަމެއް ބެހެއްޓުމަކާނުލާނަމަ، އަދަބު ކަނޑައެޅުމުގެ އަސާސީ މިންގަނޑު އެއް ދަރަޖަ މަތިވާނެއެވެ.
