# Art. 33
33. ކުށުގެ ޢަމަލެއް ކުރާއިރު، އެހެން ކުށެއް ކުރަނީކަމުގައި ކުށްހީކުރެވުން -- މީހަކު ކުށެއް ކުރުމުގައި ތިމާ ހީކުރި ގޮތަށް ޙާލަތު އޮތްނަމަ، އެ ކުރި ކުށާ އެއްވަރުގެ ނުވަތަ އެއަށް ވުރެވެސް ބޮޑު ކުށަކުން އެ މީހަކު ކުށްވެރިވާނެކަމަށް ވާނަމަ، މި ޤާނޫނުގެ 25 ވަނަ މާއްދާގައި ބަޔާންކޮށްފައިވާ ދިފާޢުގެ ފައިދާއެއް އެ މީހަކަށް ނުލިބޭނެއެވެ.
