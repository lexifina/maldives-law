# Art. 1202 (unnumbered item 6)
ޖޫރިމަނާގެ ޢަދަދު ކަނޑައެޅުން
(2) ޖޫރިމަނާ ކުރުމުގެ އަދަބު، ޢާންމުގޮތެއްގައި ވާންވާނީ އެހެން ބާވަތްތަކުގެ އަދަބުތަކާއެކު ކަނޑައެޅޭ އިތުރު އަދަބަކަށެވެ. ޖޫރިމަނާ ކުރުމުގެ އަދަބަކީ މުއްސަނދި ކުށްވެރިންގެ މައްޗަށް ކަނޑައެޅެން އޮންނަ އަދަބުތަކަށް ފައިސާއިން އަގު ދެއްކުމަށްފަހު ކުށުގެ ޙަޤީޤީ އަދަބުން އެމީހުން ސަލާމަތްވުމަށް އޮތް މަގެއްކަމަށް ނުވަތަ އެފަދަ މަގެއްކަމަށް ޤަބޫލުކުރެވޭ އަދަބެއްކަމަށް ވެގެންނުވާނެއެވެ.
