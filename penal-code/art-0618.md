# Art. 618
618. ކުށް ކަނޑައެޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ.
(1)
(i) ކުރިމަތިވެދާނެކަން އެނގޭ ނުރައްކަލެއްގެ އިންޒާރު، އެކަށީގެންވާ ސަބަބެއްނެތި ނުރައްކަލެއްގައިވާ މީހާއަށް ނުދިނުން؛ ނުވަތަ
(ii) އެހީއަށް ބޭނުންވެފައިވާ މީހާއަށް، އެކަށީގެންވާ ސަބަބެއްނެތި، އެހީތެރިކަން ފޯރުކޮށްނުދިނުން؛ ނުވަތަ
(2) އޭނާއަށް އެހީތެރިކަން ފޯރުކޮށްދެވިދާނެ ޙާލަތެއްގައި ހުރުމާއި އަދި އިންޒާރު ދެވިދާނެ ޙާލަތެއްގައި ހުރުން؛ އަދި
(i) އޭނާއަށް ނުވަތަ އެހެން މީހަކަށް ވިޔަސް އެއްވެސް ބާވަތެއްގެ މާއްދީ ނުރައްކަލެއް ނުވާނެފަދައަކުން އެހީތެރިކަން ފޯރުވައިދެވިދާނެ ނުވަތަ އިންޒާރުދެވިދާނެފަދަ ޙާލަތެއްގައި ހުރުން؛ އަދި
(ii) ޤާނޫނުން ނުވަތަ އެއްބަސްވުމެއްގެ ދަށުން އޭނާގެ މައްޗަށް ލާޒިމުކޮށްފައިވާ އެއަށްވުރެ މަތީ ވާޖިބެއް ދޫކޮށްލަންނުޖެހި އިންޒާރުދެވެން އޮތުން ނުވަތަ އެހީތެރިވެދެވެން އޮތުން.
