# Art. 1202 (unnumbered item 4)
މުއްދަތު
(4) މުޖްތަމަޢަށް ޚިދުމަތްކުރުމުގެ އަދަބަކީ ޢާންމު ގޮތެއްގައި ގިނަ ކުށްތަކަށް ކަނޑައެޅޭ އަދަބުގެ ބައެއްގެ ގޮތުގައި ހިމެނުމަށް އެކަށީގެންވާ އަދަބެކެވެ. އެހެން ނަމަވެސް މުޖްތަމަޢަށް ޚިދުމަތްކުރުމުގެ އަދަބަކީ ޢާންމުގޮތެއްގައި އެންމެ ކުޑަ ކުށްތަކަށް މެނުވީ ކަނޑައެޅޭ ހަމައެކަނި އަދަބު ކަމަށް ވެގެންނުވާނެއެވެ.
