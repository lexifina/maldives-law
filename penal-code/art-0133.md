# Art. 133
133. ކުށް ކަނޑައެޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) އެހެން މީހަކު ލައްވައި އެ މީހާގެ އައުރަ ހާމަކުރުވުން ނުވަތަ ޙަރަކާތް ދެއްކުވުން؛ އަދި
(2) މި މާއްދާގެ (ހ) ގައިވާ ޢަމަލު ހިންގީ ޖިންސީ އެދުންވެރިކަން އުފެއްދުމުގެ ނިޔަތުގައި ނުވަތަ އެދުންވެރިކަން ޙާޞިލުކުރުމުގެ ނިޔަތުގައި ކަމަށްވުން؛
