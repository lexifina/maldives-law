# Art. 538
538. ކުށް ކަނޑައެޅުން
(ހ) އަންނަނިވި ޙާލަތްތަކުގައި، އަންނަނިވި ޢަމަލުކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) ބަންދުގައި ހުރި މީހާ ފިލުމަށް މަގުފަހިކޮށްދިނުން ނުވަތަ އެހީތެރިވެދިނުން؛ ނުވަތަ
(2) މީހުން ބަންދުކުރާ މަރުކަޒެއްގެ މުވައްޒަފަކަށްހުރެ އޭނާގެ ބެލުމުގެ ދަށުގައި ބަންދުގައި ހުރި މީހަކު ފިލުމަށް އެހީތެރިވެދިނުން.
