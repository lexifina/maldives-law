# Art. 220 (unnumbered item 4)
ތިމާވެއްޓަށް ގެއްލުން ލިބޭ ޙާލަތްތަކުގައި އިތުރު ޖޫރިމަނާކުރުން
(6) "ހުއްދަ ކުރެވިފައިވާ ޖޫރިމަނާގެ ޢަދަދުތައް" މި ސުރުޚީގެ ދަށުގައި 93 ވަނަ މާއްދާ އެހެން އޮތްކަމުގައި ވީނަމަވެސް، މީހަކު މި މާއްދާގެ ދަށުން ކުށެއްކަމުގައި ބަޔާންކޮށްފައިވާ ޢަމަލު ކުރުމުގައި، ތިމާވެށީގެ ގޮތުން ބަލާއިރު މުހިންމުކަމަށް ބެލެވޭ ތަނަކަށް ނުވަތަ މުދަލަކަށް ގެއްލުމެއް ދީފިކަމަށް ވާނަމަ، އެދިން ގެއްލުމުގެ ބަދަލުގެ އިތުރުން، އެމީހަކު ގިނަވެގެން -/100,000,000 ރުފިޔާއިން ޖޫރިމަނާކުރެވިދާނެއެވެ.
