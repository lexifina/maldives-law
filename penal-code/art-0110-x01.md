# Art. 110 (unnumbered item 1)
އިންސާނާގެ ފުރާނައަށް އެއްވެސް ފަރުވާލެއްނެތި ކުރާ ޢަމަލަކުން މީހަކު މަރުވުން
(ށ) އިންސާނާގެ ފުރާނައިގެ އަގަށް އެއްވެސް ފަރުވާލެއް ނެތް ކަމަށް ދައްކުވައިދޭ ޙާލަތެއްގައި، މީހަކު ކުރާ ފަރުވާކުޑަ ޢަމަލެއްގެ ސަބަބުން، މީހަކު މަރުވެއްޖެނަމަ، އެ ޢަމަލު ހިންގި މީހާ އެކުރަނީ ކުށެކެވެ.
