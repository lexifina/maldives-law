# Art. 621
621. ކުށް ކަނޑައެޅުން
(ހ) ފައިސާ ނުވަތަ އަގު ހުރި އެއްޗެއްގެ މުޤާބިލުގައި، އަންނަނިވި ޢަމަލު ކުރާ މީހާ އެކުރަނީ ކުށެކެވެ.
(1) ހަށިވިއްކުމުގެ ޢަމަލެއް ނުވަތަ ޢަމަލުތަކެއް ކުރުމަށް މީހަކަށް މަޖުބޫރުކުރުން؛ ނުވަތަ
(2) ހަށިވިއްކުމުގެ ޢަމަލެއް ނުވަތަ ޢަމަލުތަކެއް ހިންގުމަށް ހިތްވަރު ދިނުމާއި އެކަން ހަމަޖައްސައިދިނުމާއި އެނޫންގޮތަކަށްވެސް އެކަމަށް މަގުފަހިކޮށްދިނުން؛ ނުވަތަ
(3) އޭނާގެ ބާރުގެ ދަށުގައިވާ ތަނެއް، ހަށިވިއްކުމުގެ ޢަމަލެއް ނުވަތަ ޢަމަލުތަކެއް ހިންގުމަށް ބޭނުންކުރުމުގެ ހުއްދަ ދިނުން.
