# Art. 1104 (unnumbered item 3)
އާދަޔާ ޚިލާފު ޢަމަލުގެ ސަބަބުން ކުށުގެ ދަރަޖަ ދަށްވުން
(ރ) ކުށްވެރިޔާ ކުށުގެ ޢަމަލު ހިންގީ:
(1) އެކުށް ކުރުމަށް އެކަށީގެންވާ ވަރަށް ތައްޔާރުވުމަކާ ނުލައި، ވަރަށް ކުޑަ ވަގުތު ކޮޅެއްގެ ތެރޭގައި ކަމަށްވެފައި،
(2) ކުށްވެރިޔާގެ ޢާންމު ސުލޫކާނުގުޅޭ އާދަޔާ ޚިލާފު ޙާލަތެއްގައިކަން ދޭހަކޮށްދޭ ވަގުތެއްގައި ކަމަށްވެފައި،
(3) ކުށްވެރިޔާއަކީ އެ ކުށް ކުރުމުގެ ކުރިން ޤާނޫނާއި ގަވާއިދަށް ޙުރުމަތްތެރިކޮށް ހިތަމުން އައި މީހެއްކަމަށްވާނަމަ، އޭނާގެ މައްޗަށް ދަޢުވާކުރެވިފައިވާ ކުށްތަކުގެ އަދަބުގެ ދަރަޖަ، އަދަބު ކަނޑައެޅުމުގެ އަސާސީ މިންގަޑަށްވުރެ 1 ނުވަތަ 2 ދަރަޖަ ދަށްކުރުމުގެ އިޚްތިޔާރު ކޯޓަށް ލިބިގެންވެއެވެ. މިގޮތުން އަދަބުގެ ދަރަޖަ ކޯޓުން ދަށް ކުރަންވާނީ އެއީ އިންޞާފުވެރިގޮތް ކަމަށް ކޯޓަށް ފެންނަ ނަމައެވެ.
