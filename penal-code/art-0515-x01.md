# Art. 515 (unnumbered item 1)
ދަރަޖަކުރުން
(ށ)
(1) މި މާއްދާގެ (ހ) ގައި ބަޔާންކޮށްފައިވާ ކުށެއް ކުރީ، ރައީސުލްޖުމްހޫރިއްޔާކަމުގެ ނުވަތަ ވަޒީރުކަމުގެ ނުވަތަ ރައްޔިތުންގެ މަޖިލީހުގެ މެންބަރުކަމުގެ ނުވަތަ ފަނޑިޔާރުކަމުގެ މަޤާމެއްގައި ހުރި ފަރާތަކުން ކަމުގައިވާނަމަ، އެ ކުށަކީ ޖިނާޔަތުގެ 2 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
(2) އެނޫން ޙާލަތްތަކުގައި އެ ކުށަކީ ޖިނާޔަތުގެ 3 ވަނަ ދަރަޖައިގެ ކުށެކެވެ.
