# Art. 57 (unnumbered item 1)
ޤާނޫނު އޮތް ގޮތް ނޫން ގޮތަކަށް ރަސްމީ ގޮތުން ހާމަކުރެވޭ ބަޔާނެއްގެ މައްޗަށް ބުރަވުން
(ށ) ކުށް ކުރިމީހާ، އެ ކުށް ކޮށްފައިވަނީ އަންނަނިވި ޙާލަތުގައިކަމަށް ވާނަމަ، އޭނާއަށް މަޢާފުލިބިގެންވެއެވެ:
(1) އޭނާ ކުރި ޢަމަލު އޭނާ ކުރީ ޤާނޫނުގައި ކަމެއްއޮތް ގޮތަށްކަމުގައި އަންނަނިވި ވަސީލަތްތަކުން ވަސީލަތެއްގައި، ރަސްމީ ގޮތުން ހާމަކޮށްފައިވާ ބަޔާނެއްގެ މައްޗަށް އެކަށީގެންވާ ގޮތުގައި ބުރަވެހުރެ ކަމުގައި ވުމާއި، އެ ޢަމަލު ކުރުމުގެ ފަހުގެ ތާރީޚެއްގައި، އެ ބަޔާނުގައި ހާމަކޮށްފައިވާ ހާމަކުރުމަކީ، ރަނގަޅުނޫން ނުވަތަ ކުށް ހާމަކުރުމެއްކަމުގައި ކަނޑައެޅިގެންދިއުން:
(i) ޤާނޫނަކުން؛
(ii) ޝަރުޢީ ނިންމުމަކުން، ނުވަތަ ޝަރުޢީ ލަފައަކުން، ނުވަތަ ޝަރުޢީ ނިޔާއަކުން، ނުވަތަ ޝަރުޢީ އުސޫލަކުން؛
(iii) އިދާރީ އަމުރަކުން، ނުވަތަ ދެވިފައިވާ ހުއްދައަކުން؛ ނުވަތަ
(iv) ކުށް ކަނޑައަޅާފައިވާ ޤާނޫނު ތަރުޖަމާކުރުމާއި، ހިންގުމާއި، ތަންފީޒުކުރުމުގެ ބާރު ޤާނޫނީ ހައިސިއްޔަތުން ލިބިގެންވާ ދައުލަތުގެ މުވައްޒަފެއްގެ ރަސްމީ ތަރުޖަމާއަކުން؛ އަދި
(2) އެކަމުގެ ނަތީޖާއެއްގެ ގޮތުން، އެ ކުށްކުރި ވަގުތުގައި އޭނާ އެ ކުރި ޢަމަލަކީ ޤާނޫނުގައި މަނާވެގެންވާ ޢަމަލެއްކަން އޭނާއަށް އެނގިފައިނުވުން.
