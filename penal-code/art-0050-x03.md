# Art. 50 (unnumbered item 3)
މަޢާފު ލިބެނިވި ދިފާޢު ބޭނުންކުރެވިދާނެ ފަދަ ޙާލަތްތައް އުފަންކުރުވުމަކީ އެ ދިފާޢު ނުލިބޭނެ ސަބަބަކަށް ނުވުން
(ރ) މި ބާބުގެ ދަށުން މަޢާފު ލިބެނިވި ދިފާޢެއް ބޭނުންކުރެވިދާނެ ފަދަ ޙާލަތެއް މީހަކު އަމިއްލައަށް އުފަންކުރުވުމަކީ އޭނާ ކުރި ޢަމަލާ ގުޅިގެން އެ ދިފާޢުގެ ބޭނުން ނުހިފޭނެ ސަބަބެއް ނޫނެވެ. އެހެންނަމަވެސް، އެ ޢަމަލަށް، މި މާއްދާގެ (ބ) ގެ ދަށުން އޭނާ ޒިންމާ އުފުލަން ޖެހިދާނެއެވެ.
