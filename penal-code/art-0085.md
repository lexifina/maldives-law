# Art. 85
85. ކުށެއް ކުރުމަށް އެއްބަސްވުމަށްފަހު އެކަން ދޫކޮށްލައި، ކުށުގެ ޢަމަލު ހިނގިޔަނުދިނުމުން ލިބިދޭ ދިފާޢު
(ހ) މި ޤާނޫނުގެ 80 ވަނަ މާއްދާ "ކުށެއްކުރަން އުޅުން" އާއި މި ޤާނޫނުގެ 81 ވަނަ މާއްދާ "ކުށެއް ކުރުމަށް އެދުން" އާއި މި ޤާނޫނުގެ 82 ވަނަ މާއްދާ "ކުށެއްކުރުމަށް ރޭވުން" ގެ ދަށުން ކުރެވޭ ދަޢުވާއެއްގައި ދަޢުވާ ރައްދުވާ މީހާގެ ކިބައިގައި އޮތް ކުށުގެ މަޤްޞަދު މުޅިން ދޫކޮށްލައިފިކަމާއި އެކަން ދޫކޮށްލީ އޭނާގެ އަމިއްލަ އިޚްތިޔާރުގައިކަން ރަމްޒުކޮށްދޭ ޙާލަތްތަކުގައި، ދަޢުވާ ރައްދުވާ މީހާ ކުށުގެ ޢަމަލު ހިނގިޔަނުދީ ހުއްޓުވައިފިކަމުގައި ބެލެވިއްޖެ ހިނދެއްގައި، އޭނާއަށް ދިފާޢެއް ލިބިގެންވެއެވެ.
