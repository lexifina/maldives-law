# Art. 221 (unnumbered item 3)
މާނަކުރުން
(ރ) "މުހިންމު ޢާންމު ތަންތަން" ކަމަށް ބުނެފައި އެވަނީ، ޢާންމު ފަރުދުންނަށް މުހިންމު ޚިދުމަތެއް ފޯރުކޮށްދޭ މުދަލަށާއި ވަސީލަތްތަކަށެވެ. އޭގެ ތެރޭގައި، މުހިންމު ޚިދުމަތްތައް ދެމުންގެންދާ ފާލަމާއި ޢާންމުކޮށް ބޭނުންކުރާ އެއްގަމުގެ މަގުތަކާއި، ކަނޑުގެ މަގުތަކާއި، ބަނދަރުތަކާއި، މުއާޞަލާތުގެ ބިނާތަކާއި، ޢާންމުން ބޭނުންހިފާ ތަންތަނާއި، ޓްރާންސިޓް މަރުކަޒުތަކާއި ދައުލަތުގެ ޢިމާރާތްތައް ހިމެނޭ ގޮތުންނެވެ.
