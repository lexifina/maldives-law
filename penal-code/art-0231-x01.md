# Art. 231 (unnumbered item 1)
އެނގިހުރެ ފިޔަވަޅުނާޅާކަމަށް ވާނަމަ ރުހުންދީފައިވާކަމުގައި ބެލުން
(ށ) ތިމާ ދައްކާ ވާހަކައަކީ އެހެން މީހަކު އަޑުއަހައިފާނެ ނުވަތަ ރެކޯޑުކޮށްފާނެ މަޢުލޫމާތުކަމުގައި އެނގިހުރެ އެ ވާހަކައެއް ދެއްކުން ކުރިއަށް ގެންދާ ކަމަށްވާނަމަ އޭގެ ފަހުން އަޑުއަހާ އަޑުއެހުމާއި ރެކޯޑުކުރާ ރެކޯޑު ކުރުމާއި އަދި އެ މަޢުލޫމާތު ހާމަކުރާ ހާމަކުރުމަކީ، އެ އެނގުނު އެގުމުގެ ދާއިރާގެ ތެރޭގައި، ހުއްދަކޮށްފައިވާ ކަމެއްކަމުގައި ބެލެވޭނެއެވެ.
