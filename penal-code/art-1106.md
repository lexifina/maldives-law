# Art. 1106
1106. ކުށާމެދު ދެރަވުން
(ހ) ކުށްވެރިޔާގެ މައްޗަށް ދަޢުވާ ކުރުމުގެ ކުރިން، އޭނާ ކުޅަ ކުށާމެދު ހިތުގެ އަޑިން ދެރަވާކަން ޢާންމުކޮށް ފާޅުކޮށްފިނަމަ، އޭނާގެ މައްޗަށް ކަނޑައަޅަންޖެހޭ އަދަބު، އަދަބު ކަނޑައެޅުމުގެ އަސާސީ މިންގަނޑަށްވުރެ 2 ދަރަޖަ ދަށްވާނެއެވެ. މި މާއްދާގައިވާ ގޮތުގެމަތިން އަދަބުގެ މިންވަރު ދަށްކުރެވޭނީ، އޭނާގެ މައްޗަށް ދަޢުވާ ކުރުމުގެ ކުރިން އެކުށެއް ކުރިކަމަށްބުނެ، އޭނާ ކުށަށް އިޢްތިރާފްވާ ޙާލަތްތަކުގައެވެ.
