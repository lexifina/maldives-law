# Art. 246
246. ކޮމްޕިއުޓަރ ސިސްޓަމް ބޭނުންކޮށްގެން ހިންގާ ކުޑަކުދިންގެ އޮރިޔާން ކާޑާގުޅޭ ޢަމަލުތައް
(ހ) އެނގިހުރެ، އަންނަނިވި ޢަމަލުތަކުގެ ތެރެއިން ޢަމަލެއް ކުރާ މީހާ އެކުރަނީ ކުށެކެވެ.
(1) ކޮމްޕިއުޓަރ ސިސްޓަމެއް މެދުވެރިކޮށް ކުޑަކުދިންގެ އޮރިޔާން ކާޑު ޝާއިޢުކުރުން؛
(2) ކޮމްޕިއުޓަރ ސިސްޓަމެއް މެދުވެރިކޮށް ޝާއިޢުކުރުމަށްޓަކައި ކުޑަކުދިންގެ އޮރިޔާން ކާޑު އުފެއްދުން؛
(3) ކޮމްޕިއުޓަރ ސިސްޓަމެއް ނުވަތަ ކޮމްޕިއުޓަރ ޑޭޓާ ސްޓޯރޭޖް މީޑިއަމެއްގައި ކުޑަކުދިންގެ އޮރިޔާން ކާޑު ބެހެއްޓުން.
