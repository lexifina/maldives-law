# Art. 220 (unnumbered item 5)
ތިމާވެށީގެ ގޮތުން މުހިންމުވުން
(7) އަންނަނިވި ޙާލަތްތަކުގައި ވަކި ތަނަކީ ނުވަތަ ވަކި އެއްޗަކީ ނުވަތަ ވަކި މުދަލަކީ ތިމާވެށީގެ ގޮތުން ބަލާއިރު މުހިންމުކަން ދެވޭ ތަނެއް ނުވަތަ އެއްޗެއް ނުވަތަ މުދަލެއްކަމުގައި ބެލެވޭނެއެވެ.
(i) އެއީ، ތިމާވެށީގެ ގޮތުން ޚާއްޞަ މުހިންމުކަމެއް ދެވޭ ތަނެއް، ނުވަތަ އެއްޗެއް، ނުވަތަ މުދަލެއްކަން، ޢާންމު މީހަކަށްވެސް އެނގޭ ފަދަ ތަނެއް ނުވަތަ އެއްޗެއް ނުވަތަ މުދަލަކަށްވުން ނުވަތަ ޙަޤީޤަތުގައިވެސް އެކަން އޭނާއަށް އެނގިގެންވުން؛ ނުވަތަ
(ii) ސަރުކާރުން ނުވަތަ ބައިނަލްއަޤްވާމީ ޖަމްޢިއްޔާއަކުން އެ ތަނަކީ، ނުވަތަ އެއްޗަކީ، ނުވަތަ މުދަލަކީ، އެފަދަ ޚާއްޞަ މުހިންމުކަމެއް ދެވޭ ތަނެއްކަން ނުވަތަ އެއްޗެއްކަން ނުވަތަ މުދަލެއްކަން ޤަބޫލުކޮށްފައިވުން.
