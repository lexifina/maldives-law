# Art. 84
84. ކުށް އޭނާގެ މައްޗަށް ހިންގުނު މީހާއަށް ލިބިދެވޭ ދިފާޢު -- މި ޤާނޫނުގައި އެހެން ގޮތަކަށް ބަޔާންކޮށްފައި ނުވާހާހިނދަކު، މި ޤާނޫނުގެ 81 ވަނަ މާއްދާ "ކުށެއްކުރުމަށް އެދުން" ގެ ދަށުން ނުވަތަ މި ޤާނޫނުގެ 82 ވަނަ މާއްދާ "ކުށެއް ކުރުމަށް ރޭވުން" ގެ ދަށުން ކުރެވޭ ދަޢުވާއެއްގައި، އަންނަނިވި ޙާލަތްތައް އެގޮތަށް ދިމާވުމަކީ، ދިފާޢެއް ކަމުގައި ބެލެވޭނެއެވެ:
(ހ) ދަޢުވާ ރައްދުވާ މީހާއަކީ، އެ މީހަކާ މެދު ކުށް ކުރެވުނުމީހާ ކަމުގައިވުން؛ ނުވަތަ
(ށ) ކުށް މާނަކޮށްފައިވާ ގޮތުން، ދަޢުވާ ރައްދުވާ ފަރާތުން ކުރި ޢަމަލަކީ، އޭނާގެ އިޚްތިޔާރަކާނުލައި ކުރި ޢަމަލެއް ކަމުގައި ވީނަމަވެސް، ކުށުގެ ޢަމަލު ފުރިހަމަވީ، އޭނާގެ ޢަމަލު ހިމެނިގެން ކަމުގައިވުން.
