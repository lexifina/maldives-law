# Art. 1101
1101. ކުށުގެ ނިޔަތާގުޅޭ ރުކުންތައް އިތުރުވާ ޙާލަތްތަކުގައި އަދަބުގެ މިންވަރު މަތިވުން -- ކުށްވެރިޔާގެ މައްޗަށް ސާބިތުވި ކުށް ސާބިތުކުރުމަށް ބޭނުންވާ މިންވަރަށްވުރެ މަތީ މިންވަރަކަށް ކުށުގެ ނިޔަތާގުޅޭ ރުކުންތައް، މި ޤާނޫނުގެ 24 ވަނަ މާއްދާ (ކުށުގެ ނިޔަތާގުޅޭ ރުކުންތައް) ގައި ބަޔާންކޮށްފައިވާ ގޮތުގެމަތިން، ސާބިތުވެފައިވާނަމަ، މަތިވާ ކޮންމެ ރުކުނަކަށް، އަދަބު ކަނޑައެޅުމުގެ އަސާސީ މިންގަނޑަށްވުރެ، އެއް ދަރަޖަ މަތިވާނެއެވެ.
