# Art. 1202
1202. ޢާންމު އުސޫލު
(ހ) ކުށްވެރިޔާ ކުރި ކުށުގެ އަދަބެއްގެ ގޮތުން ޖަލަށްލުން ފިޔަވާ އެހެން އަދަބެއް ކަނޑައެޅުމާއި، އެގޮތުން ކަނޑައަޅާ އަދަބުގެ މިންވަރު ބެލުމުގައި، ކުށްވެރިޔާ ކުށް ކުރި ޙާލަތަށާއި ކުށްވެރިޔާގެ ޒާތީ ޚާއްޞިއްޔަތުތަކަށާއި، މުޖްތަމަޢުގެ ބޭނުންތަކަށާއި، އަދަބު ކަނޑައެޅުމުގައި ބަލަންޖެހޭ އެހެނިހެން ކަންކަން ކޯޓުން ބަލައި، އެކަންކަމަށް ރިޢާޔަތްކުރަންވާނެއެވެ.
