# Art. 53 (unnumbered item 3)
ކުޑަކުދިންގެ މައްސަލަތައް ކުޑަކުދިންނަށް ޚާއްޞަކުރެވިފައިވާ ޖިނާއީ ޢަދުލުގެ ނިޒާމެއްގެ ތެރެއިން ހިންގުން
(ރ) ކުށްކުރި ހިނދުގައި 18 އަހަރު ފުރިހަމަނުވާ ކުޑަކުދިންގެ ތެރެއިން، މި މާއްދާގެ (ހ) އާއި (ށ) ގެ ދަށުން މަޢާފު ލިބެނިވި ދިފާޢުގެ ފައިދާ ލިބިގެންވާ ކުއްޖެއްގެ މައްސަލައިގެ އެހެން ހުރިހާ ޝަރުޢީ މަރުޙަލާތައް ކުރިއަށް ގެންދަންވާނީ ޖިނާއީ ޢަދުލުގެ ޢާންމު ނިޒާމުން ބޭރުން ކުޑަކުދިންގެ މައްސަލަތައް ބަލާ ޚާއްޞަ ނިޒާމެއްގެ ދަށުންނެވެ.
