# Art. 233
233. ކުށް ކަނޑައެޅުން
(ހ) ވަކި މަޢުލޫމާތަކީ، އަންނަނިވި ފަދަ މަޢުލޫމާތެއްކަން އެނގިހުރެ، އެހެން މީހަކަށް އެ މަޢުލޫމާތު ހާމަކުރާ މީހާ އެކުރަނީ ކުށެކެވެ:
(1) މި ޤާނޫނުގެ 231 ވަނަ މާއްދާގެ ދަށުން ނުވަތަ 232 ވަނަ މާއްދާގެ ދަށުން މަނާކޮށްފައިވާގޮތަކަށް ހޯދާފައިވާ މަޢުލޫމާތުކަން؛ ނުވަތަ
(2) އެ މަޢުލޫމާތު ހޯދުމަކީ އެހެން މީހަކަށް ހުއްދައޮތްކަމެއް ނޫންކަން.
