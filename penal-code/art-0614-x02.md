# Art. 614 (unnumbered item 2)
މާނަކުރުން
(ނ) "ދިވެހިރާއްޖޭގެ ޚާއްޞަ އިޤްތިޞާދީ ސަރަޙައްދު" ކަމަށް ބުނެފައި އެވަނީ، ދިވެހިރާއްޖޭގެ ކަނޑުގެ ސަރަޙައްދާ އިންވެގެން އޮންނަ އަދި ކަނޑުގެ ސަރަޙައްދު ގުނަން ފަށާ ހިސާބުން ފެށިގެން 200 ނޯޓިކަލް މޭލާ ހަމައަށް އެ ފުޅާމިނުގައި އޮންނަ ކަނޑުގެ ސަރަޙައްދަށެވެ. އަދި އެ ސަރަޙައްދުގެ ތެރޭގައިވާ ކަނޑުއަޑީގެ ބިމާއި، ދިރުންހުރި އެއްޗެއްސާއި ދިރުންނެތް އެއްޗެއްސާއި އިޤްތިޞާދީ ވަސީލަތްތަކާއި ކަނޑާ ގުޅުންހުރި އެކިއެކި ސައިންޓިފިކް ތަޙުލީލުތައް ކުރުމާއި ޕޮލިއުޝަން ހިފެހެއްޓުމާއި މިކަންކަން ކުރުމުގެ ބާރު ދިވެހިރާއްޖެއަށް ލިބިގެންވާ ސަރަޙައްދަށެވެ.
