# Art. 91 (unnumbered item 1)
އިހްމާލުގެ ހެކި ސާބިތުވެއްޖެކަމަށް ވާނަމަ މުޚާލަފާތަކަށް ވުރެ މަތީ ދަރަޖައެއް ކަނޑައެޅުން
(ނ) ކުށުގެ ރުކުންތައް ދެނެގަތުމުގައި އިހްމާލުވެފައިވާކަން ދަޢުވާ ކުރާފަރާތުން ސާބިތުކޮށްދޭ ޙާލަތުގައި، ނިޔަތް ސާބިތުކުރަން ނުޖެހި، ހަމައެކަނި ޢަމަލު ސާބިތުކުރަންޖެހޭ ކުށަކީވެސް މުޚާލަފާތަކަށްވުރެ މަތީ ދަރަޖައެއް ކަނޑައަޅަންޖެހިދާނެ ކުށެކެވެ. އެފަދަ ޙާލަތެއްގައި، ކުށުގެ ދަރަޖައަކަށްވާނީ، މި މާއްދާގެ (ހ) ގައި ބަޔާންކޮށްފައިވާ ދަރަޖައެވެ.
